# Onebound 1688 product search

This connector searches public 1688 product listings through [Onebound's documented `item_search` API](https://open.onebound.cn/help/api/1688.item_search.html). Onebound's official footer identifies 新余市万邦科技有限公司 as its operating company. The Query returns only product ID, title, displayed price, and public detail URL, plus page and total. It drops seller identity, request echoes, API information, and the rest of the provider payload.

`SearchProducts` sends `GET https://api-gw.onebound.cn/1688/item_search/` with keyword, one-based page, a fixed 40-item page size, key, dateline, and MD5 signature. The [official signing example](https://open.onebound.cn/help/demo/sdk/demo-sign.php) signs sorted parameter names and values with the MD5-normalized API secret. The secret is never transmitted; the key is transmitted in the HTTPS query because Onebound requires it there. The connector disables redirects and keeps the full URL, key, secret, and provider body out of failures, receipts, and results. The official signing example uses an HTTP gateway, but the product contract provides an HTTPS gateway; this connector requires HTTPS in production.

Onebound documents that both results and empty searches are billed. The `billedOperation` retry policy caps transient failures at three attempts within one minute. Provider codes `2000` (no result) and `0000` are successful `listed` outcomes; temporary error codes and 429/5xx retry; definite plan, quota, credential, and input failures select optional branches. This is a search data service; confirm API access, request frequency, and charges in your Onebound account before running live calls.

The [runnable Dex Flow](go/examples/product-search/README.md) shows connection setup and typed output. The [official Onebound site logo](https://www.onebound.cn/wp-content/themes/cross-apple/assets/images/logo.png) is embedded without alteration in `logo.svg`. Production authorization, signature acceptance, and live response variants remain unverified because no provider credentials were available.
