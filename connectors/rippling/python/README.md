# Rippling Python connector

Implements `getWorker`, returning a worker ID, visible status, and visible title. Go-recorded conformance checks exact requests, branches, retries, and outputs.

In Rippling's Developer app > API credentials, create a token with `workers.read` and save it as `api_token` in Dex Web Connections. See the [connection guide](../README.md) and [runnable example](examples/worker_inspection/README.md). Live provider authorization remains unverified.
