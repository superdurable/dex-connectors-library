# Intercom Python connector

Dex Python operations for searching and reading Intercom conversations, replying as an admin, changing conversation state, and finding contacts by email. The package uses the static connection name declared in each application and resolves the current access token for each operation attempt.

The `examples/read_conversation/` application shows a runnable Dex Flow. The `intercommock` package contains generated outcomes for deterministic application tests.

Live provider authorization and behavior remain unverified.
