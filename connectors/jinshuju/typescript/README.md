# Jinshuju TypeScript connector

Read one page of form names and tokens without submission data. Install `@superdurable/connector-jinshuju` and use `newProjectConnection` with the static connection name in the runnable [`examples/basic`](examples/basic) Flow. Configure the Access Token in Dex Web Connections. The `listFormsPage` input `next` is blank for the first page or the exact cursor from a prior result. Local conformance tests replay Go provider scenarios; live provider authorization has not been verified.
