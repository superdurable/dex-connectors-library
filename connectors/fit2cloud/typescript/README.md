# Halo TypeScript connector

Read one page of Halo article names, titles, slugs, publication state, and visibility.

Install `@superdurable/connector-fit2cloud` and use `newProjectConnection` with the static connection name in the runnable [`examples/basic`](examples/basic) Flow. Configure the connection and provider credentials in Dex Web Connections. The operation `listPosts` resolves credentials for each call. Local conformance tests replay the Go provider scenarios; live provider authorization has not been verified.
