# Productboard connector

The Go connector exposes `listFeatures`, `getFeature`, `createFeature`, `renameFeature`, and `deleteFeature` through Productboard REST API v2. The read operations return only IDs and names. `createFeature` takes a name and parent component UUID, sends at most three times after an unknown outcome, and selects `uncertain` when creation cannot be confirmed. A workspace that requires additional feature fields may reject the create. `renameFeature` replaces the name with an absolute value. `deleteFeature` permanently removes the feature and its subfeatures. HTTP 429 and transient failures retry; definite provider rejection selects an optional branch.

`listFeatures` calls `GET /entities` with `type[]=feature` and `fields[]=name`. It returns an opaque next-page cursor. Omitting `pageCursor` or leaving it blank starts at the first page; pass `nextCursor` back to read the next page. The connector accepts a `links.next` URL only at `https://api.productboard.com/v2/entities` or at `/entities` below the configured `baseUrl`, such as a proxy.

Create a Personal Access Token in [Productboard Workspace Settings > Integrations > Public APIs > Access Token](https://developer.productboard.com/reference/api-token). Enter it in Dex Web's secret `api_token` field. The public API endpoint, request timeout, and response limit have manifest defaults. See the [official List Entities reference](https://developer.productboard.com/reference/listentities) and [pagination guide](https://developer.productboard.com/reference/pagination).

The runnable Dex Flows are in [`go/examples/feature-discovery`](go/examples/feature-discovery/README.md). Their static connection name is `productboard`. Go declares `v0.3.0`; Python and TypeScript remain at `v0.2.0` with `listFeatures` only. Go-recorded conformance scenarios cover every Go operation, while language replay selects its declared operations.
