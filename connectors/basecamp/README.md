# Basecamp connector

Go implements `listAccounts`, `listProjects`, `getProject`, `listTodos`, and `getTodo`. [Python](python/README.md) and [TypeScript](typescript/README.md) implement `listAccounts` only. The account Query reads Basecamp's [authorization document](https://github.com/basecamp/bc-api/blob/master/sections/authentication.md#get-authorization), keeps only `bc3` account IDs and names, and omits the identity profile. Go resource Queries use the [Basecamp 3 API](https://github.com/basecamp/bc-api) with numeric account and resource IDs. The runnable [Go](go/examples/accounts/README.md), [Python](python/examples/accounts/README.md), and [TypeScript](typescript/examples/accounts/README.md) Flows use the static `basecamp` Dex Web connection.

At [Launchpad Integrations](https://launchpad.37signals.com/integrations), register an application and the exact redirect URL from Dex Web. Save its Client ID and secret in Dex, then authorize an identity with the desired Basecamp accounts. Dex refreshes the Bearer token; token values stay outside Flow state. Launchpad uses account consent and may ignore the requested `read` scope.

`listAccounts` accepts an optional zero-based offset and a local limit from 1 through 100; an omitted or zero offset starts at the first account, and an omitted or zero limit uses 100. The provider returns its accessible accounts in one response, so the connector bounds the response in bytes before slicing it. It retries HTTP 429, timeouts, transport failures, and server errors. Live provider authorization and Dex Web rendering remain unverified.

The Go project and to-do Queries read one provider page at a time. `listProjects` returns active projects, and `listTodos` returns pending to-dos. Obtain the account ID from `listAccounts`; use project and to-do list IDs from Basecamp results. The connector validates IDs before building URLs and treats 404 on singular reads as `notFound`. These reads are safe to repeat. List pagination beyond the first page, writes, and live provider behavior remain unverified.
