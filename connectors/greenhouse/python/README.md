# Greenhouse Python connector

Implements `getCandidate`, returning only a candidate ID and names through Harvest v3. Go-recorded conformance checks exact requests, branches, retries, and outputs. Configure Harvest v3 client credentials and the `harvest:candidates:list` scope using the [connection guide](../README.md). See the [runnable Dex Flow](examples/candidate_inspection/README.md).
