# Paddle connector

The Go, Python, and TypeScript `getTransaction` Queries read one Paddle Billing transaction's ID, status, and ISO 4217 currency. Go also supports transaction listing, draft creation, customer and billing address attachment, and cancellation; subscription listing, lookup, and next-renewal rescheduling without immediate billing; and customer, discount, product, and price listing, lookup, creation, update, and archival. Create operations have a three-send cap. Customer and discount creates store the connector call ID in Paddle `custom_data` and require that marker for read-back confirmation after an unknown outcome; products, prices, and draft transactions have no reliable unique list filter, so a bounded resend can create a duplicate entity. Paddle Billing retains catalog entities for recordkeeping, so archive replaces deletion. The language packages continue to implement only `getTransaction`.

## Connect

Sign in to the [Paddle Sandbox dashboard](https://sandbox-vendors.paddle.com) or the Live dashboard. Open **My account > Settings > Authentication > API keys > New API key**. Name the key, grant `transaction.read` plus `transaction.write`, `subscription.read`, `subscription.write`, `customer.read`, `customer.write`, `discount.read`, `discount.write`, `product.read`, `product.write`, `price.read`, and `price.write` for Go management operations, set an expiry, and save. Copy its complete secret value when shown once into the Dex Web connection's `api_key` field. The connector sends it in `Authorization: Bearer`. Revoke or rotate the key on the same API keys page. See [Paddle's authentication guide](https://developer.paddle.com/api-reference/about/authentication/).

Leave `baseUrl` blank for a `pdl_sdbx_apikey_` Sandbox key. For a `pdl_live_apikey_` Live key set `https://api.paddle.com`. Sandbox and Live keys are separate. `timeout` is a per-request Go duration and `maxResponseBytes` is a byte limit; blank uses each displayed default. Find the non-secret `txn_` ID on Paddle's Transactions page or in the create-transaction API response and pass it as `transactionId`; blank is invalid. See [Paddle's get transaction endpoint](https://developer.paddle.com/api-reference/transactions/get-transaction/).

## Examples and verification

Run the [Go](go/examples/transaction-inspection/README.md), [Python](python/examples/transaction_inspection/README.md), or [TypeScript](typescript/examples/transaction-inspection/README.md) transaction inspection Flow with the static `paddle` connection. The Go example also registers customer, discount, product, price, transaction, and subscription listing Flows. Go-recorded conformance checks exact requests, branches, retries, and outputs; language replay covers only their declared operation. Local integration tests exercise real Dex with fixture providers. Real Paddle authorization and Billing operations have not been verified locally.
