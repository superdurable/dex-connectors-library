# XiaoeTech list_root_goods_categories example

Run `uv run python -m examples.list_root_goods_categories.worker` after configuring the static `xiaoetech` connection in Dex Web. Run `uv run pytest examples/list_root_goods_categories/integration_test.py` against a local Dex stack. The integration test uses fake provider responses; live provider behavior remains unverified.
