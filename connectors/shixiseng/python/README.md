# Shixiseng Python connector

`dex-connector-shixiseng` implements the `listIndustries` Query. Configure its credential fields in Dex Web Connections using the [connector guide](../connector.yaml).

The [runnable Flow](examples/) shows Worker setup and a static `shixiseng` connection. Go-recorded scenarios replay exact provider requests and decisions. The real Dex integration test uses a fake provider; live provider authorization remains unverified.
