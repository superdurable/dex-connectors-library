# LinkedIn Ads connector

The Go, Python, and TypeScript `listAdAccounts` Queries read one cursor-based page of LinkedIn Advertising accounts visible to an authorized member. Go additionally provides `listCampaignGroups`, `listCampaigns`, and `listCreatives`. Each Query is safe to retry and returns a bounded page with a next-page token. The operations use the [LinkedIn Ad Accounts API](https://learn.microsoft.com/en-us/linkedin/marketing/integrations/ads/account-structure/create-and-manage-accounts?tabs=http&view=li-lms-2026-05), [Campaign Group API](https://learn.microsoft.com/en-us/linkedin/marketing/integrations/ads/account-structure/create-and-manage-campaign-groups?view=li-lms-2026-10), [Campaign API](https://learn.microsoft.com/en-us/linkedin/marketing/integrations/ads/account-structure/create-and-manage-campaigns?view=li-lms-2026-10), and [Creative API](https://learn.microsoft.com/en-us/linkedin/marketing/integrations/ads/account-structure/create-and-manage-creatives?view=li-lms-2026-05) with the existing `r_ads` OAuth scope. The runnable [Go](go/examples/accounts/README.md), [Python](python/examples/accounts/README.md), and [TypeScript](typescript/examples/accounts/README.md) Flows use the static `linkedin-ads` Dex Web connection.

Create or select an app in [LinkedIn Developer](https://www.linkedin.com/developers/apps), request Advertising API access under **Products**, and confirm `r_ads` appears under **Auth**. Register the redirect URL shown by Dex Web and copy the app's Client ID and Client Secret into the connection form. The member granting consent needs an appropriate Ad Account role. LinkedIn may require separate approval for programmatic refresh tokens; without one, reauthorize when the access token expires. See the [LinkedIn Marketing access guide](https://learn.microsoft.com/en-us/linkedin/marketing/increasing-access?view=li-lms-2026-09).

The API sends `Linkedin-Version: 202609` and `X-Restli-Protocol-Version: 2.0.0`. `pageSize` defaults to 100 and accepts 1–1000 for accounts, groups, and campaigns, or 1–100 for creatives. Pass `nextPageToken` as the next request's `pageToken`; a blank token means there is no next page. Group and campaign searches require a status such as `ACTIVE`, and creative searches require an account ID and campaign ID. All IDs are decimal strings without a URN prefix. LinkedIn requires `rw_ads` for mutations and `r_ads_reporting` for analytics; those capabilities require new OAuth scopes and are excluded from this compatible release.

Live LinkedIn consent, Advertising API approval, token refresh, provider reads, and Dex Web field rendering have not been verified in this checkout.
