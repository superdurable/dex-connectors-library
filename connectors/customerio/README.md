# Customer.io connector

The Go, Python, and TypeScript `getCustomersByEmail` Query finds profiles with an exact email address and returns their Customer.io `cio_id` values in provider order. Empty matches return an empty `customerIDs` list. The operation uses the read-only [App API customer lookup](https://docs.customer.io/integrations/api/app/tag/customers/getpeopleemail/) endpoint; the email is percent encoded.

Go also implements `getCampaign`, `listCampaigns`, and `getCampaignMetrics` through the [App API automation endpoints](https://docs.customer.io/integrations/api/app/). The first two return campaign ID, name, active flag, and state. Metrics use version 2 with an explicit UTC Unix-second window up to ten years and a resolution of `hours`, `days`, `weeks`, or `months`; the output keeps each provider metric's numeric series. These reads use the existing App API private key.

Go `upsertCustomer` and `deleteCustomer` call the [Track API](https://docs.customer.io/integrations/api/track/). Upsert creates a customer or changes only the supplied non-secret profile attributes, so repeating the same request is safe. Delete permanently removes a customer; a missing customer selects the optional `notFound` branch. Both operations use the Track Site ID and Track API key as HTTP Basic credentials. Event and segment writes remain unimplemented.

## Connection

In [Customer.io](https://fly.customer.io), open **Settings > API Credentials > App API** and create a private key with profile and campaign read access, or use an existing App API key. Enter the complete `sk_` key or App API key in secret `privateKey` in Dex Web Connections. For customer writes, open **Settings > API Credentials > Track API Keys** and enter the Site ID in `trackingSiteId` and the secret key in `trackingApiKey`; leaving either blank disables Track writes. See the [App API authentication guide](https://docs.customer.io/integrations/api/app/) and [Track API authentication guide](https://docs.customer.io/integrations/api/track/).

Leave `baseUrl` and `trackingBaseUrl` blank for their displayed US-region defaults, or use `https://api-eu.customer.io` and `https://track-eu.customer.io` for an EU workspace. Leave `timeout` and `maxResponseBytes` blank for their displayed defaults. Find an email on the workspace People page and pass the full address as `email`; blank is invalid. Customer writes take a workspace ID, email, or prefixed `cio_id` as `identifier`; upsert also requires a nonempty `attributes` object. Customer.io documents a 10-requests-per-second limit and returns 429 with `Retry-After` when it is exceeded.

The [Go](go/examples/customer-lookup/README.md), [Python](python/examples/customer_lookup/README.md), and [TypeScript](typescript/examples/customer-lookup/README.md) examples run the lookup operation; the Go example also runs campaigns and customer writes. Go-recorded conformance covers requests, outputs, branches, and retries; local Dex integration tests use fixtures. Live Customer.io authorization and calls remain unverified.
