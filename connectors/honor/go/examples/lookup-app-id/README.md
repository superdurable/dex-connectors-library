# HONOR App ID lookup Flow

Run `go run .` here with `DEX_FLOW_SERVICE_ADDRESS` pointing to `dexcli dev` and Dex project configuration available to `projectconfig.LoadFromEnvironment`. Add a `honor` connection in Dex Web with Client ID and API key from [Management Center > Open Capabilities > Credentials](https://developer.honor.com/cn/doc/guides/101359). Start `HONORAppIDLookup` with `{"packageName":"com.example.app"}` after binding that package in HONOR App Management. The default `foundApp` mock returns app ID 123456; `noApp` returns no match. A real connection exchanges the credentials for an account token and reads only that package's app ID.

Generate a strict FDG 2.0 graph with `dexcli visualize flow/workflow.go --schema-version 2.0 --lint app --json --out flow.fdg.json`. Run `go test ./...` for deterministic provider and Flow tests. With a running local Dex stack, run `go test -tags=integration ./examples/lookup-app-id/flow -run TestLookupAppIDUsesDefaultMockWithRealDex`; this starts the real Worker and Client against the synthetic mock. It does not verify a HONOR developer account or exchange real credentials.
