# Amplitude connector

The Go, Python, and TypeScript `searchUsers` Query searches project users by Amplitude ID, device ID, user ID, or user ID prefix. It returns the matched `userIDs` in provider order and Amplitude's `matchType`. The operation uses the read-only [Dashboard REST API User Search](https://amplitude.com/docs/apis/analytics/dashboard-rest#user-search) endpoint.

Go also provides `trackEvent` and `identifyUser`. `trackEvent` sends one event through [HTTP V2](https://www.amplitude.com/docs/apis/analytics/http-v2). Supply a user ID of at least five UTF-8 bytes, a nonempty event type, and optional string event properties. Amplitude deduplicates repeated uploads with the same Dex-derived `insert_id` for seven days, so retries are safe within the Step's one-hour default budget. `identifyUser` uses the [Identify API](https://amplitude.com/docs/apis/analytics/identify) to absolutely set one string user property with `$set`; a blank property value sets the empty string, while a blank user ID or property name is invalid. Its absolute replacement is safe to repeat. Neither operation deletes prior events or retroactively changes event properties. Both use the project's API key from the connection, without adding a new credential.

Go `getUserActivity` reads a user's event and session counts plus the event names in a bounded [User Activity](https://amplitude.com/docs/apis/analytics/dashboard-rest#user-activity) page. Pass the numeric Amplitude ID from User Lookup as `amplitudeID`, a zero-based `offset`, `limit` from 1 to 1000 (blank uses 100), and `direction` of `latest` or `earliest` (blank uses latest). The API may return extra events to preserve complete sessions; the connector caps the response at 5000 event names and never copies arbitrary event property payloads into Flow state. `unsetUserProperty` sends the Identify API's absolute `$unset` action for a `userID` and `propertyName`; both are required, and the removal affects future events only. These operations use safe retries, the existing project keys, and the regional hosts already configured.

Go `queryChart` reads a saved chart by `chartID`. Open the chart in [Amplitude Analytics](https://amplitude.com), then copy the URL segment after `/chart/` (letters, digits, underscore, or hyphen; blank is invalid). The result's `dataJSON` contains the bounded chart `data` object as compact JSON because saved chart types have different schemas. Go `getActiveUserCounts` reads an unsegmented [active or new user count](https://amplitude.com/docs/apis/analytics/dashboard-rest#get-active-and-new-user-counts) series. Use inclusive `startDate` and `endDate` in `YYYYMMDD` format, a range no longer than 366 days; `metric` is `active` or `new` (blank uses active), and `intervalDays` is 1, 7, or 30 (zero uses 1). Both queries are safe to retry and use the connection's existing Dashboard REST API keys. Their live provider responses remain unverified.

## Connection

In [Amplitude](https://amplitude.com), open **Organization settings > API Keys**, select the project, and generate or select an API key. Generate a secret key for the same project; copy its complete value when created, since the Key ID is not the secret. Enter both as secrets in Dex Web Connections. A project Manager or Admin can create keys. See [Amplitude's key guide](https://www.amplitude.com/docs/admin/account-management/manage-your-api-keys-and-secret-keys).

Leave `baseUrl` blank for the displayed US-region default, or set `https://analytics.eu.amplitude.com` for an EU project. Leave `timeout` and `maxResponseBytes` blank for their displayed defaults. Find a user ID in Amplitude User Lookup, then pass its full value or prefix as `user`. Blank is invalid. Amplitude documents a 360-query-per-hour project limit for User Search and returns 429 when exceeded; the Query retries transient failures and honors `Retry-After`.

For uploads, the connector derives the [matching ingestion host](https://www.amplitude.com/docs/apis/analytics/http-v2#regions): `api2.amplitude.com` for the default US dashboard URL, or `api.eu.amplitude.com` for the EU dashboard URL. The project API key is sent only to that ingestion host. `trackEvent` and `identifyUser` are Go-only in this release; Python and TypeScript still implement `searchUsers`.

The [Go](go/examples/user-search/README.md) example runs search, event upload, and property removal, and active user count Flows; the [Python](python/examples/user_search/README.md) and [TypeScript](typescript/examples/user-search/README.md) examples run search. Go-recorded conformance covers requests, outputs, branches, and retries; local Dex integration tests use fixtures. Live Amplitude authorization, search, activity, Identify, and event upload remain unverified.
