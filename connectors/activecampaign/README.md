# ActiveCampaign connector

The Go, Python, and TypeScript connectors list contact IDs, email addresses, and names with `listContacts` and retrieve one contact with `getContact`. Go also provides `syncContact` to create or update a contact by email and `updateContact` to replace selected fields by ID. `listContacts` input fields are optional: omitted `offset` starts at the first contact and omitted `limit` reads 20. Embedded relationships, custom field values, activity, deals, and provider links are excluded from Flow results. The account's API Key is sent in the `Api-Token` header, never in a URL or result.

Sign in to [ActiveCampaign](https://www.activecampaign.com/login), then open Settings > Developer. Copy the full account-specific API URL into `baseUrl` and the current user's API Key into the secret `api_key` field. The API URL ends in `/api/3`; blank `baseUrl` prevents connection creation. The [contact-inspection Flow](go/examples/contact-inspection/README.md) is the runnable consumer. See the [authentication guide](https://developers.activecampaign.com/reference/authentication) and [contact API](https://developers.activecampaign.com/reference/list-all-contacts).

All operations retry transport failures, HTTP 429, request timeout, and server failures. The two writes use `repeatOnUnknown: safe`: repeating `syncContact` sets the same fields for the same email, and repeating `updateContact` sets the same fields on the same contact ID. Omitted name fields leave existing values alone; supplied empty names clear them. `getContact` and `updateContact` select `notFound` on a definitive 404. Provider rejections and malformed or oversized responses select optional branches. An unwired optional branch fails the Flow. Python and TypeScript continue to replay their declared read capabilities only. Deleting a contact is excluded because the provider also anonymizes history and can delete associated deals and tasks; a duplicate or partial deletion is hard to reverse. See the [provider upsert](https://developers.activecampaign.com/reference/sync-a-contacts-data), [update](https://developers.activecampaign.com/reference/update-contact), and [delete](https://developers.activecampaign.com/reference/delete-contact) contracts.
