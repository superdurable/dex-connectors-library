# Lever Python connector

Implements `getOpportunity`, returning opportunity ID, candidate name, and stage UID. Go-recorded conformance checks exact requests, branches, retries, and outputs.

Create a Lever API key under **Settings > Integrations and API > API Credentials** and save it as `api_key` in Dex Web Connections. Leave `baseUrl` blank for the default endpoint. See the [connection guide](../README.md) and [runnable example](examples/opportunity_inspection/README.md). Live provider authorization remains unverified.
