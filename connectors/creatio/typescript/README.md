# Creatio connector for TypeScript

Implements `getContact` with the shared [manifest](../connector.yaml) and Go-recorded provider scenarios. See the [connector guide](../README.md) for Identity Service setup and renewal. The [runnable Contact Flow](examples/contact-inspection/README.md) uses the static `creatio` connection.

Run `npm ci` and `npm run check` from this directory. Live Creatio authorization remains unverified.
