# Jotform connector

The Go, Python, and TypeScript connectors list form IDs, titles, and statuses with `listForms` (an omitted or zero `offset` starts at the first form and an omitted or zero `limit` reads 20) and retrieve one submission's ID, form ID, status, and creation timestamp with `getSubmission`. The Go package also supports `getForm`, `listFormSubmissions`, `createForm`, `updateFormTitle`, `deleteForm`, `createSubmission`, `updateSubmission`, and `deleteSubmission`. Read results exclude submission answers because forms can collect secrets and personal data. Pass only non-secret answers to submission writes; their input is stored in the Flow. The API key is sent in the `APIKEY` request header, never in the URL, Flow input, or result.

Create a read-only key for Queries or a Full Access key for writes in [Jotform My Account > API](https://www.jotform.com/myaccount/api), copy it into the Dex Web secret field, and revoke it there when retired. Existing read-only keys continue to work for Queries. Use the API base URL for the account's [US, EU, or HIPAA region](https://api.jotform.com/docs/). Blank `baseUrl` uses the US default; blank timeout and response-size fields use their displayed defaults. The [Go](go/examples/form-inspection/README.md), [Python](python/examples/form_inspection/README.md), and [TypeScript](typescript/examples/form-inspection/README.md) form-inspection Flows are runnable consumers.

Queries and safe writes retry transport failures, HTTP 429, request timeout, and server failures. `createForm` and `createSubmission` use a three-send cap because the provider does not offer an idempotency key for those endpoints; after an unconfirmed final send they select `uncertain`. Provider rejections and malformed or oversized read responses select their optional branches. An unwired optional branch fails the Flow. Python and TypeScript replay only their declared operations from [Go-recorded provider scenarios](../../conformance/connectors/jotform/scenarios.json). Live Jotform authorization and write behavior remain unverified.
