# Deel Python connector

Implements `getContract`, returning the contract ID, type, and status without worker or compensation details. Go-recorded conformance checks exact requests, branches, retries, and outputs.

Create a Deel organization token with `contracts:read` under **More > Developer > Access Tokens** and save it as `api_token` in Dex Web Connections. Leave `baseUrl` blank for Sandbox or set `https://api.letsdeel.com/rest` for Production. See the [connection guide](../README.md) and [runnable example](examples/contract_inspection/README.md). Live provider authorization remains unverified.
