# Deel connector

The Go, Python, and TypeScript `getContract` Query reads a Deel contract's ID, type, and status. Go also supports `listContracts`, `listContractTasks`, `listContractAmendments`, and `listTerminationReasons`. Worker, client, compensation, task amounts, attachments, and amendment rates are excluded from Dex Results.

## Connect

In the [Deel organization](https://app.deel.com), open **More > Developer > Access Tokens > Generate new token**. Create an organization token with `contracts:read`, then copy the opaque secret into the Dex Web connection's `api_token` field. The connector sends it in the `Authorization: Bearer` header. Rotate or delete the token on the Access Tokens page. See [Deel authentication](https://developer.deel.com/api/authentication).

Leave `baseUrl` blank for the Sandbox API at `https://api-staging.letsdeel.com/rest`. For a Production token, set it to `https://api.letsdeel.com/rest`. Sandbox and Production use separate tokens. `timeout` is a per-request Go duration; `maxResponseBytes` is a byte limit. Blank uses the displayed defaults. Find the non-secret ID in Deel Contracts or an API response and pass it as `contractId`; blank is invalid. See [Retrieve a single contract](https://developer.deel.com/api/stable/reference/endpoints/contracts/get-contract).

`listContracts` reads one page of contract IDs, types, and statuses. Pass an optional `afterCursor` from the previous page and `limit` from 1–100; zero uses Deel's 50-item default. `listContractTasks` takes a `contractId` and returns task IDs and statuses. `listContractAmendments` takes `contractId`, optional `cursor`, and `limit` from 1–100 (zero uses 20), returning amendment IDs and workflow states. `listTerminationReasons` takes an optional `cursor` and `limit` from 1–100 (zero uses 20). Use each page's `nextCursor` for the next request; blank means no further page. These are read-only operations under the existing `contracts:read` token scope. See [List contracts](https://developer.deel.com/api/stable/reference/endpoints/contracts/get-contracts), [List contract tasks](https://developer.deel.com/api/endpoints/tasks/get-contract-tasks), [List amendments](https://developer.deel.com/api/endpoints/contractor-amendments/get-contract-amendments), and [List termination reasons](https://developer.deel.com/api/stable/reference/endpoints/contracts/list-contract-termination-reasons-v-2026-01-01).

## Examples and verification

Run the [Go](go/examples/contract-inspection/README.md), [Python](python/examples/contract_inspection/README.md), or [TypeScript](typescript/examples/contract-inspection/README.md) contract inspection Flow with the static `deel` connection. The Go worker also registers `DeelContractListing` for `listContracts`. Go-recorded conformance checks requests, branches, retries, and outputs for each declared language operation. Local integration tests exercise real Dex with fixture providers. Real Deel authorization and provider behavior remain unverified.
