# Box connector

The Go connector downloads one bounded Box file by numeric file ID through `downloadFile` and replaces an existing file's current content through `uploadFile`. Download returns the ID, Base64 content, and decoded byte count. Upload returns the ID, name, and SHA-1, without retaining content or tokens in its result. The [file-download Flow](go/examples/file-download/README.md) and [file-upload Flow](go/examples/file-upload/README.md) are runnable consumers.

Create an OAuth 2.0 Platform App in the [Box Developer Console](https://app.box.com/developers/console). In Configuration, enable the `root_readwrite` application scope, register the exact Dex Web redirect URI, and copy the Client ID and secret into the Dex authorization form. Box may require enterprise administrator approval. The user completing consent must have access to the file. Dex stores the access token and each rotated refresh token. See [Box OAuth setup](https://developer.box.com/guides/authentication/oauth2/oauth2-setup/), [scopes](https://developer.box.com/guides/api-calls/permissions-and-errors/scopes/), and the [download endpoint](https://developer.box.com/reference/get-files-id-content/).

The download Query retries transport failures, HTTP 429, request timeout, and server failures. HTTP 404 selects the optional `notFound` branch; an oversized file selects `tooLarge`. Upload first reads the file's name and SHA-1; it skips an already identical file, preserving version history. It uses Box's [file-version upload API](https://developer.box.com/reference/post-files-id-content) and reads back ambiguous outcomes before selecting `uncertain`. Other definitive rejections select `providerRejected`. An unwired optional branch fails the Flow. Box file events and new-file creation remain to be implemented. Live Box authorization and Dex Web setup have not been exercised.

The [Go-recorded conformance scenarios](../../conformance/connectors/box/scenarios.json) define the provider request and retry behavior for future Python and TypeScript packages.
