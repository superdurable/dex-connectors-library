# Iterable Python connector

This package implements the `getUser` Query. It returns a user's email and optional `userId`, excluding arbitrary profile data fields. Go-recorded conformance checks exact requests, branches, retries, and outputs.

Create a secret Server-side API key under **Integrations > API Keys** in the Iterable project. Save it as `api_key` in Dex Web Connections. Leave `baseUrl` blank for a US project or use `https://api.eu.iterable.com/api` for an EU project. See the [connection guide](../README.md) and [runnable example](examples/user_inspection/README.md). Live provider authorization remains unverified.
