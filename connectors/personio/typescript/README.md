# Personio Typescript connector

Implements `getPerson` for a Personio v2 person ID and names. Go-recorded conformance checks exact requests, branches, retries, and outputs. Configure a custom integration with `personio:persons:read` using the [connection guide](../README.md). The [runnable Dex Flow](examples/person-inspection/README.md) exercises the package. Live Personio authorization remains unverified.
