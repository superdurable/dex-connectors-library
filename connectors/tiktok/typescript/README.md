# TikTok for Business TypeScript connector

The `listCampaigns` Query reads a TikTok Marketing API campaign page by advertiser ID. Use the [connector authorization guide](../README.md) to configure the secret `access_token` and find the decimal advertiser ID. The [runnable Flow](examples/campaign-discovery/README.md) verifies retry and persistence with a local provider fixture. Live TikTok authorization has not been verified.
