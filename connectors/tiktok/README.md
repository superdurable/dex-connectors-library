# TikTok for Business connector

`listCampaigns` reads one page of campaign IDs and names from the [TikTok Marketing API v1.3 campaign endpoint](https://github.com/tiktok/tiktok-business-api-sdk/blob/main/js_sdk/docs/CampaignCreationApi.md). Supply the decimal Ads Manager `advertiserId`; `page` defaults to 1 and `pageSize` to 10 (maximum 1000). The result includes `page` and `totalPages`. A successful empty page returns `listed`. TikTok reports many outcomes as HTTP 200 with a nonzero body `code`. Rate limits (HTTP 429 or body code 40100), transport errors, HTTP 408, and server errors (HTTP 5xx or body codes 50000-59999) retry. Other nonzero body codes select `providerRejected`. Conclusive provider rejection and invalid responses use optional branches.

In the [TikTok API for Business Portal](https://business-api.tiktok.com/portal), create an app with Marketing API campaign read access. Under **My Apps > selected app > Basic Information**, obtain its advertiser authorization URL. After advertiser consent, exchange the returned `auth_code` with the app ID and secret at `/oauth2/access_token/`. Enter only the opaque access token in Dex Web's secret `access_token` field. In [Ads Manager](https://ads.tiktok.com), find the advertiser ID under **Account Name > ID**. Leave `baseUrl`, `timeout`, and `maxResponseBytes` blank for their displayed defaults. Live TikTok authorization and provider calls have not been verified.

Runnable examples: [Go](go/examples/campaign-discovery/README.md), [Python](python/examples/campaign_discovery/README.md), [TypeScript](typescript/examples/campaign-discovery/README.md).
