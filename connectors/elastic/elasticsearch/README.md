# Elasticsearch connector

The first Go release provides `searchDocuments`, `indexDocument`, and `deleteDocument` for one concrete index. Search returns total-hit information and each hit's ID, score, and source JSON. Indexing fully replaces one document under a caller-supplied stable ID; deletion ensures that ID is absent. Use an existing index without nonrepeatable ingest pipeline effects for index retries. Search source is untrusted provider data; restrict index permissions and avoid placing credentials in documents that a Flow can read.

Set `clusterUrl` to the HTTPS Direct endpoint at https://cloud.elastic.co/ > deployment > Manage > Application endpoints > Elasticsearch, or a self-managed cluster HTTP endpoint. In Kibana, create a native user under **Stack Management > Security > Users** and a role under **Stack Management > Security > Roles** with `read`, `index`, or `delete` for the intended index pattern, according to the operations used. Assign the role while creating the user, then save its username and secret password in Dex Connections. This initial Basic-auth connector targets Elastic Stack deployments, not Elastic Cloud Serverless. See [Elasticsearch security permissions](https://www.elastic.co/docs/deploy-manage/users-roles/cluster-or-deployment-auth/kibana-role-management).

`searchDocuments` selects `found`, `indexNotFound`, `providerRejected`, `invalidResponse`, or `defect`. HTTP 429, 503, other server errors, transport failures, timed-out searches, and shard failures retry under the default one-hour policy. The connector requests `allow_partial_search_results=false`. `indexDocument` selects `indexed`, `providerRejected`, or `defect`; `deleteDocument` selects `absent`, `indexNotFound`, `providerRejected`, or `defect`. Their fixed-ID writes are safe to repeat. The connector retries transport, rate-limit, server, and unconfirmed response failures until its retry budget ends. A repeated deletion that finds no document completes through `absent` with `wasDeleted: false`. Writes use Elasticsearch's default refresh timing, so an immediate search may briefly see the prior state. Runnable examples cover [search](go/examples/document-search/README.md), [replacement](go/examples/document-index/README.md), and [deletion](go/examples/document-delete/README.md).
