# WordPress connector

The WordPress Go connector reads and manages posts, pages, and users through the core REST API. The Python and TypeScript packages retain their existing post operations. `getPost` reads one numeric post ID. `listPosts` reads one page of published posts and returns WordPress's total-count headers. A draft returned to `getPost` selects `notFound` so private content does not enter a read Flow. `createPost` defaults to draft and can publish immediately when its input explicitly selects `publish`.

Configure `siteUrl` with the HTTPS Site Address shown at **Settings > General** in your own `/wp-admin/options-general.php`. Do not include `/wp-json`. In **Users > Profile > Application Passwords** at `/wp-admin/profile.php`, create an application password for the Dex connection. Enter your WordPress username and that password in the connection. The password is secret and never belongs in Flow input. Draft creation needs `edit_posts`; publishing also needs `publish_posts`. See the [WordPress application-password guide](https://developer.wordpress.org/rest-api/using-the-rest-api/authentication/) and [role capabilities](https://wordpress.org/documentation/article/roles-and-capabilities/).

The Go package also offers `updatePost`, `deletePost`, `createPage`, `getPage`, `listPages`, `updatePage`, `deletePage`, `getUser`, `listUsers`, and `updateUser`. Post and page deletion moves content to Trash. User creation is excluded because the REST API requires a password, which must not enter Flow input; user deletion requires a permanent delete and post reassignment. Page creation uses a three-send cap and the optional `uncertain` branch. Reads, absolute updates, and reversible Trash operations use safe retries. `createPost` retains its existing single-dispatch behavior. Published title and content are untrusted HTML; sanitize before display.

The runnable [post-inspection](go/examples/post-inspection/README.md) and [post-creation and update](go/examples/post-creation/README.md) examples show operation-specific Step factories and the static `wordpress` connection. The Python and TypeScript packages replay their declared operations from the [Go-recorded provider scenarios](../../conformance/connectors/wordpress/scenarios.json) and include runnable [Python](python/README.md) and [TypeScript](typescript/README.md) Flows.
