# WordPress connector

The WordPress Go and Python connectors read published posts and creates drafts or published posts through the core REST API. `getPost` reads one numeric post ID. `listPosts` reads one page of published posts and returns WordPress's total-count headers. A draft returned to `getPost` selects `notFound` so private content does not enter a read Flow. `createPost` defaults to draft and can publish immediately when its input explicitly selects `publish`.

Configure `siteUrl` with the HTTPS Site Address shown at **Settings > General** in your own `/wp-admin/options-general.php`. Do not include `/wp-json`. In **Users > Profile > Application Passwords** at `/wp-admin/profile.php`, create an application password for the Dex connection. Enter your WordPress username and that password in the connection. The password is secret and never belongs in Flow input. Draft creation needs `edit_posts`; publishing also needs `publish_posts`. See the [WordPress application-password guide](https://developer.wordpress.org/rest-api/using-the-rest-api/authentication/) and [role capabilities](https://wordpress.org/documentation/article/roles-and-capabilities/).

The `getPost` branches are `found`, `notFound`, `providerRejected`, `invalidResponse`, and `defect`. The `listPosts` branches are `listed`, `providerRejected`, `invalidResponse`, and `defect`. Read operations retry HTTP 429, server errors, and transport failures under the default one-hour policy. `createPost` selects `created`, `providerRejected`, `uncertain`, or `defect`. It records a single-dispatch checkpoint because WordPress offers no create-post idempotency key. An unconfirmed send fails as `uncertain` and is not repeated; check the site's Posts list before creating another post. Published title and content are untrusted HTML; sanitize before display.

The runnable [post-inspection](go/examples/post-inspection/README.md) and [post-creation](go/examples/post-creation/README.md) examples show operation-specific Step factories and the static `wordpress` connection. The Python package replays the [Go-recorded provider scenarios](../../conformance/connectors/wordpress/scenarios.json) and includes runnable [Python Flows](python/README.md). TypeScript follows after its own conformance port.
