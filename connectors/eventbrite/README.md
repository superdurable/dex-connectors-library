# Eventbrite connector

The Go connector reads accessible organization IDs with `listOrganizations`, lists an organization's events with `listEvents`, reads one event with `getEvent`, and retrieves one attendee with `getAttendee`. `listAttendeesByEvent` and `listAttendeesByOrganization` return attendee IDs, event IDs, statuses, and creation times. `getOrder`, `listOrdersByEvent`, and `listOrdersByOrganization` return order IDs, event IDs, statuses, and creation times. Event mutations include `createEvent`, `copyEvent`, `updateEvent`, `publishEvent`, `unpublishEvent`, `cancelEvent`, and `deleteEvent`. Attendee profiles, answers, barcode values, purchaser details, and payment data stay out of Flow results.

In [Eventbrite Account Settings > Developer Links > API Keys](https://www.eventbrite.com/account-settings/apps), create an API key if necessary and copy its **Private Token** into the Dex Web secret field. The provider receives it only in an `Authorization: Bearer` header. The default API root is `https://www.eventbriteapi.com/v3`; the endpoint override exists for trusted test gateways.

Run [organization-inspection](go/examples/organization-inspection/README.md) with the static `eventbrite` connection to obtain an organization ID. Pass that ID to organization lists or `createEvent`; use an event ID for event lists and mutations, an event and attendee ID for `getAttendee`, and an order ID for `getOrder`. Page inputs are one-based, with zero selecting page one. Lists return provider pagination metadata. `createEvent` needs a name, RFC 3339 UTC start and end, IANA time zone, and uppercase ISO 4217 currency code. It creates a draft; add description, organizer, ticket, and payment settings in Eventbrite before publishing.

Queries retry transport failures, HTTP 429, request timeout, and server errors. Event state mutations check or read back the event before repeating a write. `createEvent` and `copyEvent` can make at most three possible sends; an unconfirmed write at the cap selects `uncertain`. A definitive 404 selects `notFound` when applicable; `deleteEvent` treats an absent event as deleted. Rejections and malformed or oversized read responses select optional branches. Unwired optional branches fail the Flow. The [Python package](python/README.md) implements the original three Queries and replays their Go-verified conformance scenarios. The [TypeScript package](typescript/README.md) implements the same three Queries. Go, Python, and TypeScript packages await independent release.
