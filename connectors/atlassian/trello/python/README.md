# Trello Python connector

`dex-connector-atlassian-trello` implements the `listCards`, `getCard`, `createCard`, `updateCard`, and `addComment` Steps from `connector.yaml`. Create and comment calls use a Dex heartbeat fence before sending; ambiguous outcomes select `uncertain` and are never resent automatically. `updateCard` uses absolute values and reads the card back to confirm the update.

It also implements the `cardChanged` poll Trigger at parity with the Go connector, on the Python SDK's durable poll Trigger kit (`dex_connectors.sdk.pollingtrigger`, `dex-connectors-sdk>=0.12.0`). Each binding polls one board's action history every `pollInterval` (at least 10 seconds; blank keeps 30 seconds), re-reads the last minute, skips the action IDs it already delivered, and delivers the rest oldest first, 500 per page. The first poll records a baseline and delivers no earlier action. A backlog over 10,000 actions, a 400 that rejects `since` or `before`, a cursor for another board, or an undecodable cursor records a new baseline; a 429 pauses every binding of the connection for one 10-second rate-limit window. Delivery is at least once, and each action keeps the Trigger event ID `trello-action-<action ID>` across refetches. Cursor tokens and inbox payloads are byte-compatible with the Go connector, so Go and Python replicas can share one binding.

- `new_project_card_trigger_runner(project, connection_name, routes)` opens the connection, loads each binding's saved board, and records every action in the binding's project Trigger inbox before its poll cursor commits. A binding without a saved board raises `ValueError`.
- `new_card_trigger_runner(CardTriggerRunnerConfig(...))` takes targets and cursor stores directly; `new_card_changed_trigger(...)` keeps its cursor in memory and records a new baseline on every start.
- `define_card_changed_trigger_binding(...)` declares a binding with its `boardInput` unit.

See [`examples/approved_request_card`](examples/approved_request_card) for a runnable Dex Flow and [`examples/card_changed`](examples/card_changed/README.md) for a Flow started by `cardChanged`. Configure its static `ConnectionName` through Dex Web Connections with a Trello API key and user token. Provider authorization and live Trello behavior are not verified by local replay tests.
