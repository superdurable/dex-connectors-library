# Teamwork.com Typescript connector

Implements `getTask`, returning a task ID, name, and status. Go-recorded conformance checks exact requests, branches, retries, and outputs.

In the Teamwork.com site, open **avatar > Edit my details > API & Mobile > Show your token** and save the secret Key as `api_token` in Dex Web Connections. Set required `baseUrl` to the site HTTPS root. See the [connection guide](../README.md) and [runnable example](examples/task-inspection/README.md). Live provider authorization remains unverified.
