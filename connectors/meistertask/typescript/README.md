# MeisterTask TypeScript connector

Implements `getTask`, returning a task ID, numeric status code, and name. Go-recorded conformance checks exact requests, branches, retries, and outputs.

At [MindMeister API](https://www.mindmeister.com/api), create a personal access token with `userinfo.profile`, `userinfo.email`, and `meistertask` scopes and save it as `api_token` in Dex Web Connections. See the [connection guide](../README.md) and [runnable example](examples/task-inspection/README.md). Live provider authorization remains unverified.
