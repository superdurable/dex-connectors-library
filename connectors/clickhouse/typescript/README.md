# ClickHouse TypeScript connector

Implements `listTables` with a typed database name, returning up to 100 sorted table names and `hasMore`. Go-recorded conformance checks exact HTTP requests, branches, retries and outputs. Configure the HTTP endpoint, database username and secret password using the [connection guide](../README.md). See the [runnable Dex Flow](examples/table-inspection/README.md). Live provider authorization remains unverified.
