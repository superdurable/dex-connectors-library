# Drip connector

The Go, Python, and TypeScript connectors list accessible account IDs and names with `listAccounts`, then read one subscriber's ID, email, name, and status with `getSubscriber`. Go also supports `listSubscribers` for bounded pages, `upsertSubscriber` for creation and identity updates, and `deleteSubscriber` for permanent removal. Address, custom fields, tags, and tracking data remain outside Flow results. Use an account ID from `listAccounts` for subscriber operations.

Go also supports `listCampaigns` and `getCampaign` for email series campaign IDs, names, and states, plus `activateCampaign` and `pauseCampaign` for state changes. Campaign listing accepts a one-based page and optional status (`draft`, `active`, `paused`), sort (`created_at`, `name`), and direction (`asc`, `desc`); blank values use Drip defaults. A 422 state response is checked with a campaign read and succeeds only when the target state is confirmed. These safe operations retry rate limits, 503, other server errors, and transport failures. See the [Drip campaign API](https://developer.drip.com/#email-series-campaigns) and the [Go campaign page Flow](go/examples/account-discovery/README.md).

Go also offers `listCampaignSubscribers` with status, page, page size, and direction filters, and `listSubscriberCampaignSubscriptions` for one subscriber's campaign memberships. `subscribeToCampaign` takes an account ID, campaign ID, and email address. It is limited to three possible sends because subscription can deliver email; retries read back the subscriber's membership, and an unconfirmed capped attempt selects `uncertain`. `removeSubscriberFromCampaign` and `unsubscribeSubscriberFromAll` converge on removal and global unsubscribe states. See the [Drip subscription API](https://developer.drip.com/#email-series-campaigns) and the [Go campaign subscribers Flow](go/examples/account-discovery/README.md).

For a private integration, open [your Drip user profile](https://www.getdrip.com/user/edit), copy the personal API Token, and save it in the Dex Web secret `api_key` field. The connector sends it as the HTTP Basic username with an empty password. Leave `baseUrl` blank for the Drip API v2 default. Public integrations use OAuth. See the [Drip API reference](https://developer.drip.com/) for authentication and endpoint details.

Queries retry transport failures, HTTP 429, timeout, and server failures. The Go subscriber upsert and delete operations are safe to repeat: they set one subscriber to the same values or ensure the subscriber is absent. Definite rejections, malformed or oversized JSON, invalid input, and a missing subscriber select optional branches. The [Go account and subscriber discovery Flows](go/examples/account-discovery/README.md), [Python account discovery Flow](python/examples/account_discovery/README.md), and [TypeScript account discovery Flow](typescript/examples/account-discovery/README.md) are runnable consumers. The Python and TypeScript packages replay their declared subset of Go-recorded provider scenarios. Live Drip authorization remains unverified.
