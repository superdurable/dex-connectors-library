# Amazon SES connector

`getEmailIdentity` reads the verification status of an email address or domain through the [Amazon SES v2 GetEmailIdentity API](https://docs.aws.amazon.com/ses/latest/APIReference-V2/API_GetEmailIdentity.html). The `found` branch returns `EmailIdentityDetails {name, verificationStatus}`. The optional `missing` branch handles an identity absent from the selected AWS Region. Rate limits, transport failures, HTTP 408, and server failures retry. Other definitive rejections and malformed responses use optional branches. Requests use AWS Signature Version 4.

In [Amazon SES Console](https://console.aws.amazon.com/ses), open **Verified identities**, select the email address or domain, and use the console Region selector for `region`. Enter the exact identity value as `emailIdentity` in the Flow input. In [IAM Console](https://console.aws.amazon.com/iam), open **Users > selected user > Security credentials > Access keys > Create access key**. Grant `ses:GetEmailIdentity` for the identity ARN. Copy the access key ID and one-time secret access key into their respective secret fields; set `session_token` for temporary credentials. Leave `endpoint` blank for the regional AWS API. Leave `timeout` and `maxResponseBytes` blank for their displayed defaults. Rotate credentials through IAM when needed.

Runnable examples: [Go](go/examples/identity-lookup/README.md), [Python](python/examples/identity_lookup/README.md), [TypeScript](typescript/examples/identity-lookup/README.md). Tests use local HTTP fixtures; live AWS authorization and calls have not been verified.
