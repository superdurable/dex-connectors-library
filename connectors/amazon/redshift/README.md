# Amazon Redshift connector

`getStatementResult` fetches one page of a completed SQL statement's cached JSON results through the [Redshift Data API](https://docs.aws.amazon.com/redshift-data/latest/APIReference/API_GetStatementResult.html). Supply `statementId`, the UUID returned by `ExecuteStatement` or `BatchExecuteStatement`, and `nextToken` from an earlier page (blank for the first page). The `fetched` branch returns `records` as arrays of Redshift Field objects, `totalNumRows`, and `nextToken`; continue until the token is blank. The optional `missing` branch handles a result that Redshift no longer retains. Throttling, 429, 408, 5xx, and transport errors retry. Definitive rejection, malformed responses, and invalid input take optional branches. Requests use AWS Signature Version 4 with service `redshift-data`.

In the [Redshift Query Editor v2](https://console.aws.amazon.com/redshiftv2), select the Region and run a SQL statement through the Data API using JSON result format. Copy its statement `Id` to Flow input. In the [IAM Console](https://console.aws.amazon.com/iam), open **Users > selected user > Security credentials > Access keys > Create access key**. Grant `redshift-data:GetStatementResult` and consider the [statement owner IAM condition](https://docs.aws.amazon.com/redshift/latest/mgmt/data-api-iam.html) to restrict result access. Enter the access key ID and one-time secret in Dex secret fields; temporary credentials also need their STS session token. Leave `endpoint` blank for the regional AWS API and leave `timeout` and `maxResponseBytes` blank for displayed defaults. Never put credentials in Flow input or logs.

The [Go](go/examples/statement-results/README.md), [Python](python/examples/statement_results/README.md), and [TypeScript](typescript/examples/statement-results/README.md) examples run a typed Flow. [Go-recorded conformance scenarios](../../../conformance/connectors/amazon/redshift/scenarios.json) cover results, pagination, missing statements, rejection, throttling, server errors, transport failure, and invalid input. Provider fixtures and real Dex Worker tests are included. Live AWS authorization and a real statement result fetch have not been verified.
