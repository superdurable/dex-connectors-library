# TypeScript Redshift statement results example

The Worker runs `AmazonRedshiftStatementResultsTypeScript` through the static `amazon-redshift` connection and stores the result page in an Attribute. From `connectors/amazon/redshift/typescript`, run `npm run example:worker` with the project `DEX_PROJECT_*` environment and a running `dexcli dev` service. Run `npm run example:start -- <statement-uuid> [next-token]`; omit the token for the first page, then pass each returned `nextToken` to fetch another page. Optional branches are unwired. The integration test runs the same Flow against real Dex and a local provider fixture. Configure the connection with the [connector guide](../../../README.md).
