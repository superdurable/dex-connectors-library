# Amazon DynamoDB connector

`getItem` reads one table item by its complete primary key through the [DynamoDB GetItem API](https://docs.aws.amazon.com/amazondynamodb/latest/APIReference/API_GetItem.html). Supply `tableName`, a `key` map with one partition attribute and an optional sort attribute, and `consistentRead` to request a strongly consistent read. Each key attribute is a DynamoDB AttributeValue object with one nonempty `S`, `N`, or base64 `B` value. The `found` branch returns `exists: true` and the raw `Item` AttributeValue map. The optional `missing` branch returns `exists: false` and an empty item map. AWS throttling, 429, 408, 5xx, and transport errors retry. Definitive provider rejection, invalid responses, and invalid input take optional branches. AWS Signature Version 4 signs the JSON protocol POST.

In the [DynamoDB Console](https://console.aws.amazon.com/dynamodb), open **Tables**, choose the table and note its name, partition key, optional sort key, and console Region. In the [IAM Console](https://console.aws.amazon.com/iam), open **Users > selected user > Security credentials > Access keys > Create access key**. Grant `dynamodb:GetItem` on the table ARN. Enter the access key ID and one-time secret access key in their secret fields. For temporary credentials also enter the STS session token. Leave `endpoint` blank for the regional AWS endpoint; leave `timeout` and `maxResponseBytes` blank for the displayed defaults. Never put credentials in Flow input or logs.

The [Go](go/examples/item-lookup/README.md), [Python](python/examples/item_lookup/README.md), and [TypeScript](typescript/examples/item-lookup/README.md) examples run the same typed Flow. The Go-recorded [conformance scenarios](../../../conformance/connectors/amazon/dynamodb/scenarios.json) cover found and missing items, composite keys, definitive errors, throttling, server errors, transport failure, and invalid input. Provider fixtures and real Dex Worker tests are included. Live AWS authorization and an actual DynamoDB table read have not been verified.
