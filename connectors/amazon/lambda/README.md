# Amazon Lambda connector

`getFunction` reads a function name and ARN through the [AWS Lambda GetFunction API](https://docs.aws.amazon.com/lambda/latest/api/API_GetFunction.html). Supply a function name of 1–64 letters, digits, underscores, or hyphens. The `found` branch returns `FunctionDetails {name, arn}`; the optional `missing` branch handles a function absent from the selected Region. Rate limits, transport errors, HTTP 408, and server errors retry. Other definitive provider errors and malformed responses select optional branches. Requests use AWS Signature Version 4.

In [AWS Lambda Console](https://console.aws.amazon.com/lambda), open **Functions**, select the function, and read its name and ARN from **Function overview**. The console Region selector determines the `region` connection field. In [IAM Console](https://console.aws.amazon.com/iam), open **Users > selected user > Security credentials > Access keys > Create access key**. Grant the user `lambda:GetFunction` for the function ARN. Copy the access key ID and secret access key into their respective secret fields; the secret value is displayed only once. Set `session_token` as well for temporary credentials. Leave `endpoint` blank to use the regional AWS API. Leave `timeout` and `maxResponseBytes` blank for the displayed defaults. Rotate credentials through IAM when needed.

Runnable examples: [Go](go/examples/function-lookup/README.md), [Python](python/examples/function_lookup/README.md), [TypeScript](typescript/examples/function-lookup/README.md). Tests use a local HTTP fixture; live AWS authorization and calls have not been verified.
