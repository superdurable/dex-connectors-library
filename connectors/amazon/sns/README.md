# Amazon SNS connector

`listTopics` reads one page of topic ARNs through the [Amazon SNS ListTopics API](https://docs.aws.amazon.com/sns/latest/api/API_ListTopics.html). Pass an empty `nextToken` for the first page, then pass the returned `nextToken` to read the next page. The `page` branch returns `TopicPage {topicARNs, nextToken}`; an empty list is a valid page. SNS returns up to 100 topics per request.

Go also supports `createTopic` (safe: SNS returns the existing ARN for an owned name), `deleteTopic` (safe, also removes subscriptions), `setTopicAttribute` (safe absolute replacement), and `publishMessage` (limited to three possible sends). `publishMessage` sends a plain UTF-8 body to a topic using a signed POST, returns `messageID` when accepted, and can return `uncertain` after an unknown outcome because SNS offers no message deduplication for standard topics. Its message is limited to 256 KiB, the default SNS topic limit; a topic with a different limit may reject it. Optional non-happy branches fail a Flow when unwired. Rate limits, transport failures, HTTP 408, and server failures retry under each operation's repeat tier. Requests use AWS Signature Version 4.

In [Amazon SNS Console](https://console.aws.amazon.com/sns), open **Topics** and select the Region. Set that code in the connection's `region` field. Copy a selected topic's full **Topic ARN** for `deleteTopic`, `setTopicAttribute`, or `publishMessage`; `createTopic.name` is a standard topic name of 1–256 letters, digits, underscores, or hyphens. For `setTopicAttribute`, use `DisplayName` with a sender label, `TracingConfig` with `PassThrough` or `Active`, or `MaximumMessageSize` with an integer number of bytes from 1024 to 1048576. The `attributeValue` is a nonempty full replacement; blank is invalid. `publishMessage.subject` may be blank, which omits the optional email subject; the body must be nonempty UTF-8 text. In [IAM Console](https://console.aws.amazon.com/iam), open **Users > selected user > Security credentials > Access keys > Create access key**. Grant `sns:ListTopics` and the permissions for operations you use (`sns:CreateTopic`, `sns:DeleteTopic`, `sns:SetTopicAttributes`, `sns:Publish`), then copy the access key ID and one-time secret access key into their respective secret fields. Set `session_token` for temporary credentials. Leave `endpoint` blank for the regional AWS API. Leave `timeout` and `maxResponseBytes` blank for their displayed defaults. Rotate credentials through IAM when needed.

Runnable examples: [Go](go/examples/topic-listing/README.md), [Python](python/examples/topic_listing/README.md), [TypeScript](typescript/examples/topic-listing/README.md). Tests use local HTTP fixtures; live AWS authorization and calls have not been verified.
