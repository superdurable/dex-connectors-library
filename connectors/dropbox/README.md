# Dropbox connector

The Go connector lists a bounded folder page with `listFolder`, follows its cursor with `continueFolder`, reads one file or folder identity with `getMetadata`, and downloads bounded file content with `downloadFile`. Results contain IDs, names, display paths, entry kinds, and a continuation cursor; unselected provider fields and token material do not enter Flow state. `downloadFile` deliberately persists the requested file content as Base64. A `listFolder` result with `hasMore: true` can be passed to `continueFolder` until all entries are enumerated; the cursor can also read later changes.

Create a Scoped access app in the [Dropbox Developer Console](https://www.dropbox.com/developers/apps). Choose App folder or Full Dropbox, enable `files.metadata.read` and `files.content.read` under Permissions, and register the exact redirect URI shown by Dex Web under Settings > OAuth 2. Copy App key and App secret into the Dex authorization form, then complete user consent. Dex stores the short-lived access token and refresh token. See the [Dropbox OAuth guide](https://docs.dropboxapi.com/dropbox-api/docs/oauth), [list folder API](https://docs.dropboxapi.com/dropbox-api/api-reference/user-endpoints/files/list-folder), [get metadata API](https://docs.dropboxapi.com/dropbox-api/api-reference/user-endpoints/files/get-metadata), and [download API](https://docs.dropboxapi.com/dropbox-api/api-reference/user-endpoints/files/download). Runnable consumers are the [folder-discovery Flow](go/examples/folder-discovery/README.md), [folder-continuation Flow](go/examples/folder-continuation/README.md), and [file-download Flow](go/examples/file-download/README.md).

All four Queries retry transport failures, HTTP 429, request timeout, and server failures. A Dropbox 409 with `path/not_found` selects the optional `notFound` branch; other definitive rejections select `providerRejected`. Malformed metadata selects `invalidResponse`; a file over `maxDownloadBytes` selects `tooLarge`. An unwired optional branch fails the Flow. Live Dropbox authorization and Dex Web setup have not been exercised.
