# X Python connector

This package implements `getPost` for Dex Python Flows. It reads only a Post ID and text from X REST API v2. Go-recorded conformance scenarios verify exact requests, branches, retries, and outputs.

Create a Project and App in the [X Developer Console](https://console.x.com), then copy its app Bearer Token from **Keys and tokens** into Dex Web secret `access_token`. Leave `baseUrl` blank for the public endpoint. See the [connector README](../README.md) and runnable example. Live X API access remains unverified.
