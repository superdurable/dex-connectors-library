# X Post connector

The Go, Python, and TypeScript `getPost` Queries read one public Post's decimal ID and text through [X API v2 Post lookup](https://docs.x.com/x-api/posts/lookup/introduction). Go v0.2.0 adds `searchRecentPosts` and `getUser`, both safe Queries; the Python and TypeScript packages remain at v0.1.0 with `getPost` only. X returns Post and user data inside `data`; the connector omits media, metrics, and error details. HTTP 404, or an HTTP 200 `errors` array without `data` whose problem type is `resource-not-found`, selects `notFound` for single lookups. A `not-authorized-for-resource` or `client-forbidden` problem without `data` selects `providerRejected`; 429, transport failures, and 5xx responses retry.

`searchRecentPosts` reads one page from the last seven days using X's [recent search API](https://docs.x.com/x-api/posts/search-recent-posts). `query` is a 1–4096 character search expression; `maxResults` accepts 10–100 and zero uses the API default of 10. A blank `nextToken` starts at the first page. `getUser` reads a public profile by a username of up to 15 letters, digits, or underscores, without `@`. The application Bearer Token cannot create or delete Posts, send direct messages, like, repost, or change List membership; those n8n write actions require user authorization and a connection change.

Create or select a Project and App in the [X Developer Console](https://console.x.com), confirm Post read access and API usage balance, then copy its **Bearer Token** from **Keys and tokens**. Save it in Dex Web's secret `access_token` field. This app token reads public Posts; it is not a user OAuth access token. Rotate it in the same console and update the connection if revoked. Pass the numeric value after `/status/` in an x.com Post URL as `postId`.

The runnable [Go](go/examples/post-inspection/README.md), [Python](python/examples/post_inspection/README.md), and [TypeScript](typescript/examples/post-inspection/README.md) Flows use the static `x-twitter` connection. Live X authorization, API billing access, provider reads, and Dex Web field rendering have not been verified here.
