# SurveyMonkey connector

The Go connector provides `listSurveys`, `getSurvey`, `createSurvey`, `updateSurvey`, `deleteSurvey`, `listCollectors`, `getCollector`, `createCollector`, `updateCollector`, `deleteCollector`, `listResponses`, `getResponse`, and `deleteResponse`. Python and TypeScript continue to provide `listSurveys` and `getResponse`. Questions, answers, respondent IP addresses, collector passwords, and custom variables are excluded from Flow results. The Access Token is sent in an Authorization Bearer header, never in a URL or result.

Create a private app in [SurveyMonkey Developer Portal](https://developer.surveymonkey.com), open My Apps > the app > Settings, and copy its Access Token into the Dex Web secret field. Public app tokens require View Surveys and View Responses for reads, Create/Modify Surveys for survey writes, View Collectors plus Create/Modify Collectors for collector operations, and Create/Modify Responses for response deletion. SurveyMonkey approval is required for public app survey and response write scopes, and non-weblink collector creation requires a paid plan. Use the [v3 API URL](https://api.surveymonkey.com/v3/docs) matching the account's US, EU, or Canadian region. Blank `baseUrl` uses the US default. The [survey-inspection Flows](go/examples/survey-inspection/README.md) are runnable consumers.

Queries and safe update/delete operations retry transport failures, HTTP 429, request timeout, and server failures. `getResponse`, `getSurvey`, and `getCollector` select `notFound` on a definitive 404. `listResponses` returns response IDs and pagination metadata without answer content. `deleteResponse` requires both collector and response IDs and treats a definitive 404 as already absent. `createSurvey` and `createCollector` are limited to three possibly effective sends: the provider offers no unique client marker to reconcile by, so a title or name alone is never used as proof of creation. An unconfirmed create selects `uncertain` at the send cap. Provider rejections and malformed or oversized read responses select optional branches. An unwired optional branch fails the Flow. The Python and TypeScript packages replay the unchanged operations they implement.

Response creation and answer updates are outside this connector's safe metadata-only result contract. SurveyMonkey webhooks require a registered public callback and `webhooks_write` authorization; this connector does not register or receive webhook deliveries.
