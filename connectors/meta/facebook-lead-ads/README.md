# Facebook Lead Ads connector

The Go and Python connectors implement `listLeadForms` for a Page and `getLead` for one lead ID. The [lead-form Flow](go/examples/lead-forms/README.md) and [lead-inspection Flow](go/examples/lead-inspection/README.md) are runnable consumers. `getLead` returns only ID, form ID, ad ID, and creation time; it does not request or persist form answers, which may contain sensitive personal data. Lead event delivery and the TypeScript package remain to be implemented. The [Python lead-form Flow](python/examples/lead_forms/README.md) exercises `listLeadForms`; Go-recorded provider scenarios cover both Python operations.

Create or select a Meta Business app with Marketing API access in [Meta for Developers](https://developers.facebook.com/apps/). Grant the token holder lead access to the Page and its forms. In [Graph API Explorer](https://developers.facebook.com/tools/explorer/), select the app, request `leads_retrieval` and the Page permissions needed for your Page, then choose Get Token > Get Page Access Token. Save the complete token only in the Dex secret `page_access_token` field. Meta may require App Review and advanced access for production Pages. Find the numeric Page ID in Meta Business Suite > Settings > Business assets > Pages. `listLeadForms` returns form IDs; a `leadgen` webhook or Ads Manager supplies lead IDs. Leave the versioned Graph API URL, timeout, and response limit at their displayed defaults unless your account needs a supported override.

The Queries retry transport failures, HTTP 429, request timeout, and server failures. A definite HTTP 404 selects `notFound`; other definitive rejections select `providerRejected`; malformed or oversized JSON selects `invalidResponse`. Optional branches are unwired by default and fail the Flow. The token and provider error body are excluded from failures and Flow results.

Meta's [Page lead-form SDK edge](https://github.com/facebook/facebook-python-business-sdk/blob/main/facebook_business/adobjects/page.py) and [lead retrieval guidance](https://github.com/facebookincubator/catalogue-of-api-solutions/blob/main/solutions/leads/leads-retrieval-set-up-checker.md) describe the underlying Graph API calls. Live Page authorization, Dex Web setup, and provider responses remain unverified.
