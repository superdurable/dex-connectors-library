# Meta Ads Insights Python connector

`getAd` reads one Meta Marketing API ad's ID, name, configured status, and effective status through a static Dex `meta-ads-insights` connection. See the [connector guide](../README.md) and the [runnable Python Flow](examples/ad_inspection/README.md). Go-recorded provider scenarios are replayed by `tests/test_conformance.py`. Live Meta authorization remains unverified.
