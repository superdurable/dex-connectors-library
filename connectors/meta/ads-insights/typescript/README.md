# Meta Ads Insights TypeScript connector

`getAd` reads one Meta Marketing API ad's ID, name, configured status, and effective status. It uses the static `meta-ads-insights` Dex connection with a Marketing API access token granted `ads_read`. See the [connector guide](../README.md) and [runnable TypeScript Flow](examples/ad-inspection/README.md). The package replays Go-recorded provider scenarios. Live Meta authorization remains unverified.
