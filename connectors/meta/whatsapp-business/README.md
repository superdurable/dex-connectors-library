# WhatsApp Business Platform connector

The Go connector's `listPhoneNumbers` Query reads one page of business phone-number IDs, verified names, and display numbers from a WhatsApp Business Account (WABA). It returns Meta's `after` cursor when another page is available. The [phone-number inspection Flow](go/examples/phone-numbers/README.md) is a runnable consumer. Sending text or template messages and receiving webhook events remain to be implemented.

Create a Meta business portfolio, WhatsApp Business Account, business phone number, and Meta app. In [Meta Business Settings](https://business.facebook.com/settings/system-users), assign the WABA to a system user and generate a secret access token with `whatsapp_business_management`. Save that token only in the Dex connection. Find the numeric WABA ID under Business Settings > Accounts > WhatsApp Accounts and pass it as `businessAccountId` in the Flow input; leave `after` blank for the first page. The connector uses the versioned Graph API endpoint from the manifest. Meta's [official Cloud API collection](https://www.postman.com/meta/whatsapp-business-platform/documentation/wlk6lh4/whatsapp-cloud-api) documents the account setup, token permissions, `GET /{WABA-ID}/phone_numbers`, and pagination.

The Query retries transport failures, HTTP 429, request timeout, and server failures. HTTP 404 selects the optional `notFound` branch; malformed or oversized JSON selects `invalidResponse`; other definitive rejections select `providerRejected`. An unwired optional branch fails the Flow. The output excludes the access token and unneeded provider fields. Live Meta authorization and Dex Web setup have not been exercised.
