# Facebook Pages TypeScript connector

Read a Page feed with `listPosts` or inspect one post with `getPost`. The result includes only post ID, message, creation time, and permalink; comments and reactions are excluded. The static `facebook-pages` connection uses a Page access token. See the [connector README](../README.md) for Meta setup and the [runnable Flow](examples/page-posts/README.md) for Dex usage. The package replays Go-recorded provider scenarios.
