# Instagram Business TypeScript connector

`listMedia` reads one cursor page of Instagram professional account media: IDs, captions, media types, timestamps, and permalinks. It uses the static `instagram-business` Dex connection with a Meta User access token. See the [connector guide](../README.md) and [runnable TypeScript Flow](examples/media-list/README.md). The package replays Go-recorded provider scenarios. Live Meta authorization remains unverified.
