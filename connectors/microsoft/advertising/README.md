# Microsoft Advertising connector

This connector reads and manages campaigns through Microsoft's [Campaign Management v13 REST API](https://learn.microsoft.com/en-us/advertising/campaign-management-service/campaign-management-service-operations?view=bingads-13). Go provides `listCampaigns`, `getCampaign`, `createCampaign`, `updateCampaign`, and `deleteCampaign`. Python and TypeScript continue to provide `listCampaigns` only and replay its [Go-recorded provider scenarios](../../../conformance/connectors/microsoft/advertising/scenarios.json).

`listCampaigns` takes a numeric account ID and returns each campaign's ID, name, type, and status. It requests all currently documented campaign types explicitly because the API otherwise defaults to Search. An empty list is a successful result. HTTP 408, 429, 5xx, and transport failures retry; rejected requests and malformed responses select optional branches. The example leaves those branches unwired, so they fail the Flow.

Register a Web application in [Microsoft Entra](https://entra.microsoft.com/) with the exact Dex Web redirect URI and the Microsoft Advertising `msads.manage` delegated permission. Dex requests `offline_access` and refreshes tokens. Obtain a developer token from the [Microsoft Advertising Developer Portal](https://developers.ads.microsoft.com/). In the signed-in Campaigns URL, `cid` is the customer ID for the connection and `aid` is the account ID passed to the Flow. Keep the client secret and developer token in Dex credentials, never Flow input or Results.

Runnable campaign discovery examples are available for [Go](go/examples/campaign-discovery/README.md), [Python](python/examples/campaign_discovery/README.md), and [TypeScript](typescript/examples/campaign-discovery/README.md). They demonstrate the Query through Dex with a mock provider. Live authorization and campaign reads have not been verified without a user-controlled advertising account.

`getCampaign` reads one ID. `createCampaign` creates a paused Search campaign with a unique name, a positive daily budget in the account currency, and a Microsoft Advertising time-zone value. It reads the account's campaigns by name before a possible resend. `updateCampaign` changes only the supplied name, status, or daily budget; `deleteCampaign` removes one ID. These operations use the existing `msads.manage` scope. Creation has a three-send cap and may select `uncertain` when read-back cannot confirm the outcome. Live campaign writes remain unverified.
