# Microsoft Teams Python connector

`dex-connector-microsoft-teams==0.1.0` provides the four Microsoft Teams operations for Dex Flows. Configure a named Microsoft Teams connection in Dex Web before running a Flow. Live Microsoft authorization and provider calls have not been verified.

Decoded sender IDs and Graph request IDs retain printable values up to 128 bytes; message type, importance, and content type are limited to 64 bytes.
