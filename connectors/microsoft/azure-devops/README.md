# Azure DevOps connector

The Go, Python, and TypeScript connectors list one bounded page of accessible project IDs, names, and states with `listProjects`, and reads a work item's ID, title, state, and type with `getWorkItem`. It excludes descriptions, identity details, links, and other provider fields from Flow state.

Sign in to [Azure DevOps](https://dev.azure.com/) and open your organization. Copy the organization URL into `baseUrl`. Under user settings > Personal access tokens > New Token, create an organization-scoped token with **Project and Team (Read)** and **Work Items (Read)** scopes and store its one-time value in Dex secret `personal_access_token`. The connector sends it as the password of HTTP Basic authentication with an empty username. See [Microsoft's PAT guidance](https://learn.microsoft.com/en-us/azure/devops/organizations/accounts/use-personal-access-tokens-to-authenticate?view=azure-devops), [project list API](https://learn.microsoft.com/en-us/rest/api/azure/devops/core/projects/list?view=azure-devops-rest-7.1), and [work item API](https://learn.microsoft.com/en-us/rest/api/azure/devops/wit/work-items/get-work-item?view=azure-devops-rest-7.1). Runnable project-discovery Flows are provided for [Go](go/examples/project-discovery/README.md), [Python](python/examples/project_discovery/README.md), and [TypeScript](typescript/examples/project-discovery/README.md).

Both Queries retry transport failures, HTTP 429, request timeout, and server failures. `getWorkItem` selects `notFound` on a definitive 404. Provider rejections and malformed or oversized responses select optional branches. An unwired optional branch fails the Flow. Live provider authorization has not been exercised.
