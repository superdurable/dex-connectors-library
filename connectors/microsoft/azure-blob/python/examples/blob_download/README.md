# Python Azure Blob download example

The Worker runs `MicrosoftAzureBlobDownloadPython` through the static `microsoft-azure-blob` connection and stores the bounded download in an Attribute. From `connectors/microsoft/azure-blob/python`, run `uv run python -m examples.blob_download.worker` with the project `DEX_PROJECT_*` environment and a running `dexcli dev` service. Start the Flow with a unique ID and `GetBlobInput(container="docs", blob_name="example.txt")`, using your actual container and path. Optional branches are unwired. `integration_test.py` runs the same Flow against real Dex and a local provider fixture. Configure the connection with the [connector guide](../../../README.md).
