# Azure Blob Storage connector

`getBlob` downloads one complete blob through the [Azure Storage Get Blob REST API](https://learn.microsoft.com/en-us/rest/api/storageservices/get-blob). Supply `container` and `blobName` (including `/` for a virtual folder). The `downloaded` branch returns the bounded bytes in `dataBase64`, plus `contentType` and `etag`. Decode base64 in the consuming application when bytes are needed. The optional `missing` branch handles a nonexistent container or blob. HTTP 429, 408, 5xx, and transport failures retry. Definitive rejection, invalid metadata, oversized bodies, and invalid input take optional branches.

This release uses [Shared Key authorization](https://learn.microsoft.com/en-us/rest/api/storageservices/authorize-with-shared-key). In the [Azure portal](https://portal.azure.com), open **Storage accounts > selected account > Overview** to copy `accountName`, then **Security + networking > Access keys > Show keys** to copy one base64 key value into the secret `account_key` field. The account must allow Shared Key; accounts that disable it cannot use this release. Under **Data storage > Containers**, select the container and blob path for the Flow input. Leave `endpoint`, `timeout`, and `maxResponseBytes` blank for their displayed defaults. The default download limit is 1 MiB; increase it only for content safe to store in a Flow Result. Rotate the key by updating the connection to the other key before regenerating the old one. Never put keys in Flow input or logs.

The [Go](go/examples/blob-download/README.md), [Python](python/examples/blob_download/README.md), and [TypeScript](typescript/examples/blob-download/README.md) examples run the same typed Flow. [Go-recorded conformance scenarios](../../../conformance/connectors/microsoft/azure-blob/scenarios.json) cover downloaded and missing blobs, nested paths, rejection, metadata errors, retries, and invalid input. Provider fixtures and real Dex Worker tests are included. Live Azure authorization and a real blob download have not been verified.
