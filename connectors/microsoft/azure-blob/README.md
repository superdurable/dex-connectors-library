# Azure Blob Storage connector

Go provides `listContainers`, `getContainer`, `createContainer`, `deleteContainer`, `getBlob`, `listBlobs`, `putBlob`, and `deleteBlob` through the [Azure Blob REST API](https://learn.microsoft.com/en-us/rest/api/storageservices/Blob-Service-REST-API). Python and TypeScript retain `getBlob` only. Container listing is paged; `getContainer` returns an ETag and last modified date. Named creation distinguishes an existing container, and deletion accepts an already missing container. Supply `container` and `blobName` (including `/` for a virtual folder). `getBlob` returns bounded bytes as base64, `contentType`, and `etag`; decode base64 in the application when bytes are needed. `listBlobs` returns one bounded page of names and a continuation marker, optionally filtered by prefix. `putBlob` creates or absolutely replaces a block blob from base64 bytes and returns its ETag. `deleteBlob` removes a blob and its snapshots; a missing blob counts as deleted. The new writes use `safe` repeat semantics because replacement and deletion are absolute operations on the same name. HTTP 429, 408, 5xx, and transport failures retry. Definitive rejection, invalid metadata, oversized bodies, and invalid input take optional branches.

This release uses [Shared Key authorization](https://learn.microsoft.com/en-us/rest/api/storageservices/authorize-with-shared-key). In the [Azure portal](https://portal.azure.com), open **Storage accounts > selected account > Overview** to copy `accountName`, then **Security + networking > Access keys > Show keys** to copy one base64 key value into the secret `account_key` field. The account must allow Shared Key; accounts that disable it cannot use this release. Under **Data storage > Containers**, select the container and blob path for the Flow input. Leave `endpoint`, `timeout`, and `maxResponseBytes` blank for their displayed defaults. The default download limit is 1 MiB; increase it only for content safe to store in a Flow Result. Rotate the key by updating the connection to the other key before regenerating the old one. Never put keys in Flow input or logs.

The [Go](go/examples/blob-download/README.md), [Python](python/examples/blob_download/README.md), and [TypeScript](typescript/examples/blob-download/README.md) examples run typed Flows. Go also includes a blob listing Flow. [Go-recorded conformance scenarios](../../../conformance/connectors/microsoft/azure-blob/scenarios.json) cover the Go operations; language ports replay `getBlob` only. Provider fixtures and real Dex Worker tests are included. Live Azure authorization, upload, deletion, and download have not been verified.
