# Jiandaoyun TypeScript connector

Read application IDs and names authorized by the API key.

Install `@superdurable/connector-fanruan` and use `newProjectConnection` with the static connection name in the runnable [`examples/basic`](examples/basic) Flow. Configure the connection and provider credentials in Dex Web Connections. The operation `listAppsPage` resolves credentials for each call. Local conformance tests replay the Go provider scenarios; live provider authorization has not been verified.
