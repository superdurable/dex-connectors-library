# Odoo TypeScript connector

Implements `searchPartners` for company partner IDs and names through Odoo JSON-2. Go-recorded conformance checks exact requests, branches, retries, and outputs. Configure the site origin, database, and secret API key using the [connection guide](../README.md). See the [runnable Dex Flow](examples/partner-search/README.md).
