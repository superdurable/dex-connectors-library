# ClickUp task event Trigger

This TypeScript example records one verified `taskStatusUpdated` webhook in a Dex Flow. `app.ts` starts the HTTP endpoint at `/webhooks/clickup`, uses the project Trigger inbox to persist a delivery before answering `200`, and starts a real Worker. If Dex is unavailable, the endpoint can keep recording; the Worker retries until Dex is reachable. After a restart, the runner replays pending events. `resolveFlowId` maps redelivery of one ClickUp event to the same Flow.

Start `dexcli dev`. In Dex Web, create `clickup-workspace` with the personal API token from [ClickUp Settings > Apps](https://app.clickup.com/settings/apps) and the `webhook_secret` returned when you [create a webhook](https://developer.clickup.com/reference/createwebhook). The token starts with `pk_`; the signing secret is opaque and remains private. Configure the `task-status-changes` Trigger binding's **Task events** picker for `taskStatusUpdated`. Blank accepts all supported task events at the binding, while the example Flow admits only status changes. The webhook itself must subscribe to `taskStatusUpdated`.

Expose `WEBHOOK_BIND_ADDRESS` (default `127.0.0.1:8853`) through a public HTTPS tunnel, register `https://<host>/webhooks/clickup` as the endpoint, and save the webhook's one-time `secret` in the Connection. `GET /readyz` answers `200` once the binding can receive. From `connectors/clickup/typescript`, with the `DEX_PROJECT_*` environment generated by Dex Web:

```sh
DEX_FLOW_SERVICE_ADDRESS=127.0.0.1:8801 npm run example:event
```

Generate and validate the Flow Definition Graph 2.0 source:

```sh
npm run build
npm install --prefix examples/task-event --no-save --no-package-lock --ignore-scripts .
dexcli visualize examples/task-event/flow/workflow.ts --language typescript --schema-version 2.0 --lint app --json --out - --open=false
```

`npm run test:integration` verifies signed delivery, forgery rejection, deduplication, and replay after Dex downtime against a real Dex Worker and Client with a local signed webhook fixture. Live ClickUp webhook delivery and authorization have not been verified.
