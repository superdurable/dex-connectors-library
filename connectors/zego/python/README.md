# ZEGO Python connector

`dex-connector-zego` implements the `getRoomUserCount` Query. Configure its credential fields in Dex Web Connections using the [connector guide](../connector.yaml).

The [runnable Flow](examples/) shows Worker setup and a static `zego` connection. Go-recorded scenarios replay exact provider requests and decisions. The real Dex integration test uses a fake provider; live provider authorization remains unverified.
