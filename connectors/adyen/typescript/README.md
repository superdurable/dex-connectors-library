# Adyen TypeScript connector

Implements `getPaymentLink`, returning a payment link ID, status, and amount currency. Go-recorded conformance checks exact requests, branches, retries, and outputs.

Create a secret API key in Adyen Customer Area > Developers > API credentials and grant the Checkout webservice role. Save it as `api_key` in Dex Web Connections. See the [connection guide](../README.md) and [runnable example](examples/payment-link-inspection/README.md). Live provider authorization remains unverified.
