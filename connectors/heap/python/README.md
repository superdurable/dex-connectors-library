# Heap Python connector

This package implements `setUserProperties`. It sends absolute string property values for a stable Heap identity; Go-recorded conformance checks exact requests, branches, retries, and outputs. The Result only reports acceptance.

In Dex Web Connections, enter the non-secret numeric environment `appId` from [Heap Projects](https://heapanalytics.com). Leave `baseUrl` blank for US or use `https://c.eu.heap-api.com` for EU. See the [connection guide](../README.md) and [runnable example](examples/user_properties/README.md). Live Heap acceptance remains unverified.
