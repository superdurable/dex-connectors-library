# Heap connector

The Go, Python, and TypeScript `setUserProperties` Mutations send absolute string property values for one stable identity to Heap's server-side [Add User Properties API](https://developers.heap.io/reference/add-user-properties). Go also exposes `trackEvent` and `setAccountProperties`. Repeating property updates overwrites those values with themselves; results only report acceptance.

## Connect

Sign in to [Heap](https://heapanalytics.com), open **Account > Manage > Projects**, select the environment, and copy its numeric app ID into Dex Web `appId`. The ID is not secret; blank prevents calls. These ingestion endpoints do not use an authorization token. Leave `baseUrl` blank for the displayed US endpoint; for EU projects enter `https://c.eu.heap-api.com`. Do not append an API path. Leave `timeout` and `maxResponseBytes` blank for the displayed defaults; overrides use a positive Go duration and a positive byte count respectively. See [Heap's regional endpoint guidance](https://developers.heap.io/reference/server-side-apis-overview).

Pass a unique, permanent identity already used by Heap and one to fifty non-secret string properties, with names and values under 1024 bytes. A missing identity creates a user profile without events. Heap blocks `id` as a property name. Do not use a shared identity such as `guest`: merging people under one identity damages analytics. The server-side endpoint permits 30 requests per 30 seconds per identity and app ID. Select the right production or test app ID before starting a Flow.

`trackEvent` sends one custom event for an identified user. Its `idempotency_key` is derived from the stable Dex call ID, so unknown outcomes safely retry without duplicating the event. Event names are at most 1024 bytes; optional timestamps use RFC3339, and event properties must exclude `user_id`, `session_id`, and `screen_name`. `setAccountProperties` overwrites selected string values for an account ID configured in Heap; repeated requests are safe. Both operations use the existing app ID and regional endpoint. Heap's separate user deletion API requires a new auth token and is not available through this connector.

The runnable [Go](go/examples/user-properties/README.md), [Python](python/examples/user_properties/README.md), and [TypeScript](typescript/examples/user-properties/README.md) examples use the static `heap` connection. The Go Flow tracks a profile event before setting properties. Go-recorded conformance scenarios cover request shape, validation, rejection, and retryable statuses; the unchanged language packages replay their declared operation. Each example's mock integration test runs against a real Dex server. Real Heap ingestion and Dex Web configuration have not been verified with a Heap account.
