# Lingxing ERP Amazon stores

This connector lists authorized Amazon stores via Lingxing ERP's [official HTTPS store-list API](https://apidoc.lingxing.com/new/api-docs/BasicData/SellerLists/). Lingxing identifies its China mainland company as [深圳市领星网络科技有限公司](https://www.lingxing.com/about). The Query returns only the Lingxing store ID, display name, Amazon region, country, and synchronization status. It excludes Amazon seller/account IDs, account names, request IDs, and raw provider responses. The API is unpaginated and returns every authorized store; this connector returns the first 200 and sets `truncated` when additional stores were omitted.

The client obtains a short-lived token with AppID/AppSecret through the [official token endpoint](https://apidoc.lingxing.com/new/api-docs/Authorization/GetToken/), caches it in memory until shortly before expiry, and sends it only in an `Authorization: Bearer` header. It signs the [store request](https://apidoc.lingxing.com/new/guides/new-instructions/) using ASCII-sorted parameters, uppercase MD5, AES/ECB with PKCS padding, and base64, matching the official Go SDK. The token participates in the signature but is absent from the URL. The AppID and signature are in the HTTPS URL per provider contract. Credentials and provider error bodies never enter Flow input, results, receipts, logs, or failure messages. Redirects are disabled.

In Lingxing ERP, a super administrator enables **Settings > Business Configuration > Global > Open Interface**, enters the notification email, and uses **Open Backend > API Information** to get AppID/AppSecret. The same page configures the outbound public IP allowlist. See [official setup guidance](https://apidoc.lingxing.com/new/guides/app-id/). Both credentials are protected connection fields. IP allowlisting and account API entitlement must be complete before the Flow can call the provider.

The [runnable Dex Flow](go/examples/stores/README.md) demonstrates the static `lingxing` connection and typed output. The [official Lingxing site logo](https://static.distributetop.com/office-site-new/office-site-upload/img/logo.838214a.png) is embedded without alteration in `logo.svg`. Production authorization, signature acceptance, token expiry behavior, and live responses remain unverified because no provider credentials were available.
