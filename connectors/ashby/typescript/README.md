# Ashby TypeScript connector

Implements `getCandidate`, returning candidate ID, name, and creation/update timestamps. Go-recorded conformance checks exact requests, branches, retries, and outputs.

Create an Ashby API key with **Candidates read** permission under **Admin > API Keys** and save it as `api_key` in Dex Web Connections. Leave `baseUrl` blank for the default endpoint. See the [connection guide](../README.md) and [runnable example](examples/candidate-inspection/README.md). Live provider authorization remains unverified.
