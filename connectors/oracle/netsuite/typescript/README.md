# Oracle NetSuite connector for TypeScript

This package implements `getCustomer` with the shared [manifest](../connector.yaml) and Go-recorded provider scenarios. See the [connector guide](../README.md) for OAuth setup and retry behavior. The [runnable customer Flow](examples/customer-inspection/README.md) uses the static `oracle-netsuite` Dex Web connection.

Run `npm ci` and `npm run check` from this directory. Live Oracle NetSuite authorization and Dex Web field rendering have not been verified.
