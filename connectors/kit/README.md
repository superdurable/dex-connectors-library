# Kit connector

The Go connector lists one cursor page of subscribers with `listSubscribers` and reads one subscriber with `getSubscriber`. It returns only subscriber ID, email address, first name, and lifecycle state. Custom fields, attribution, tags, and location stay out of Flow results. List results use the provider's `end_cursor` for the next page and request `slim=true` to avoid extra fields.

For automation of your own account, open [Kit Developer settings](https://app.kit.com/account_settings/developer_settings), choose Add a new key under V4 API Keys, and copy the one-time value into the Dex Web connection's secret `api_key` field. The legacy V3 API Secret does not work. The connector sends the key only in the `X-Kit-Api-Key` header. Leave `baseUrl` blank for the displayed API v4 default. Kit requires OAuth for public App Store integrations. See [authentication](https://developers.kit.com/api-reference/authentication), [list subscribers](https://developers.kit.com/api-reference/subscribers/list-subscribers), and [get a subscriber](https://developers.kit.com/api-reference/subscribers/get-a-subscriber).

Both reads retry transport failures, HTTP 429, request timeout, and server failures. `getSubscriber` selects `notFound` on a definitive 404. Provider rejections and malformed or oversized responses select optional branches. The [subscriber-inspection Flow](go/examples/subscriber-inspection/README.md) is the runnable consumer. Live Kit authorization remains unverified.
