# Kit connector

The Go, Python, and TypeScript connectors list one cursor page of subscribers with `listSubscribers` and read one subscriber with `getSubscriber`. Go also provides `upsertSubscriber`, `listTags`, `createTag`, `tagSubscriber`, and `removeTagFromSubscriber`. Subscriber results contain only ID, email address, first name, and lifecycle state. Custom fields, attribution, and location stay out of Flow results. List results use the provider's `end_cursor` for the next page and request `slim=true` for subscribers.

For automation of your own account, open [Kit Developer settings](https://app.kit.com/account_settings/developer_settings), choose Add a new key under V4 API Keys, and copy the one-time value into the Dex Web connection's secret `api_key` field. The legacy V3 API Secret does not work. The connector sends the key only in the `X-Kit-Api-Key` header. Leave `baseUrl` blank for the displayed API v4 default. Kit requires OAuth for public App Store integrations. See [authentication](https://developers.kit.com/api-reference/authentication), [list subscribers](https://developers.kit.com/api-reference/subscribers/list-subscribers), and [get a subscriber](https://developers.kit.com/api-reference/subscribers/get-a-subscriber).

All new Go writes use safe repeat semantics: [subscriber creation](https://developers.kit.com/api-reference/subscribers/create-a-subscriber) upserts by email, [tag creation](https://developers.kit.com/api-reference/tags/create-a-tag) reuses a case-insensitive name, and [tag assignment](https://developers.kit.com/api-reference/tags/tag-a-subscriber) returns an existing association on repeats. [Tag removal](https://developers.kit.com/api-reference/tags/remove-tag-from-subscriber) is a repeatable delete. Use a valid subscriber email, a nonblank tag name, and positive IDs from Kit's **Grow > Subscribers** and tag pages. A tag application can trigger Kit automations configured for that tag. A blank cursor starts the first list page; zero `perPage` uses 20.

Queries and mutations retry transport failures, HTTP 429, request timeout, and server failures. `getSubscriber` and tag membership mutations select `notFound` on a definitive 404. Provider rejections and malformed or oversized responses select optional branches. The [subscriber-inspection Flow](go/examples/subscriber-inspection/README.md) is the runnable consumer and also lists one page of tags. Python and TypeScript replay only their published read capabilities from the Go-recorded scenarios. Live Kit authorization remains unverified.
