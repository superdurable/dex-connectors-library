# Chargebee connector

The Go, Python, and TypeScript `getSubscription` Query reads a Chargebee subscription's ID, status, and currency code. Go also provides safe `listSubscriptions`, `getCustomer`, `listCustomers`, `getInvoice`, `listInvoices`, `getEvent`, and `listEvents` Queries. Python and TypeScript retain `getSubscription` only. Customer reads return ID and optional email without cards or balances. Invoice reads return ID, status, currency, and total in the currency's minor unit without payment details. Event reads return only ID, type, and occurrence time in Unix seconds; event content and user identity are excluded. Chargebee's event list is eventually consistent, and individual event retrieval is limited to recent events.

List operations accept `limit` from 1 to 100 and an opaque `offset` returned as `nextOffset`; zero limit and blank offset use the provider's first page defaults. Get operations take the non-secret ID shown in the corresponding Chargebee console page or returned by a list operation. Blank IDs are invalid. The connector's authorization guide intentionally uses a Read-Only key, so customer creation, subscription cancellation, and webhook registration available in n8n cannot run through existing connections without a credential policy change.

## Connect

Sign in to your Chargebee Test or Live site at [app.chargebee.com](https://app.chargebee.com). In **Settings > Configure Chargebee > API Keys and Webhooks > API Keys**, add a **Read-Only** API key, then save its complete secret in Dex Web `api_key`. Chargebee uses the key as the HTTP Basic username with an empty password. See [Chargebee API keys](https://www.chargebee.com/docs/billing/2.0/site-configuration/api_keys) and [authentication](https://apidocs.chargebee.com/docs/api/v2/pcv-1/auth).

Set the non-secret `baseUrl` to `https://{site}.chargebee.com/api/v2`, replacing `{site}` with the subdomain of the Chargebee site that issued the key. Test and Live keys are separate. `timeout` is a per-request Go duration and `maxResponseBytes` is a byte limit; blank uses the displayed defaults. Find a subscription ID in Chargebee Subscriptions or an API response and pass it as `subscriptionId`. See [subscriptions](https://apidocs.chargebee.com/docs/api/subscriptions/list-subscriptions), [customers](https://apidocs.chargebee.com/docs/api/customers/list-customers), and [invoices](https://apidocs.chargebee.com/docs/api/invoices/list-invoices).

## Examples and verification

Run the [Go](go/examples/subscription-inspection/README.md), [Python](python/examples/subscription_inspection/README.md), or [TypeScript](typescript/examples/subscription-inspection/README.md) Flow with the static `chargebee` connection. The Go example also lists one subscription page. Go-recorded conformance checks requests, branches, retries, and outputs, with the language ports replaying their existing operation. Local integration tests exercise real Dex with fixture providers. Real Chargebee authorization and retrieval remain unverified.
