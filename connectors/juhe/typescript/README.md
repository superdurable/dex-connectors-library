# Juhe TypeScript connector

Read current weather for one supported Chinese city with `getCurrentWeather`. Install `@superdurable/connector-juhe` and use `newProjectConnection` with the static connection name in the runnable [`examples/basic`](examples/basic) Flow. Configure the API 73 key in Dex Web Connections. The key stays outside Flow input and persisted output. Local conformance tests replay Go provider scenarios; live provider authorization has not been verified.
