# Google Ads connector

The Go, Python, and TypeScript `listAccessibleCustomers` Queries return customer resource names directly accessible to the connected Google identity. They use the [v26 CustomerService endpoint](https://developers.google.com/google-ads/api/rest/common/others) and accept a local result limit so a large account list does not enter Dex Flow state unexpectedly. The Go module additionally provides `listCampaigns`, `getCampaign`, `createCampaign`, `updateCampaignStatus`, and `removeCampaign` through [v26 Search and Mutate](https://developers.google.com/google-ads/api/rest/design/service-methods). The runnable [Go](go/examples/customers/README.md), [Python](python/examples/customers/README.md), and [TypeScript](typescript/examples/customers/README.md) examples use the static `google-ads` Dex Web connection.

`listCampaigns` returns one page with `nextPageToken` and optional status and date filters; `getCampaign` reads one numeric campaign ID. Both return selected campaign identity and performance totals, with cost in micros. `createCampaign` requires an existing budget resource name and explicit EU political advertising declaration. It creates a paused Search campaign with manual CPC and uses a bounded `limited` retry with at most three possible sends. Campaign names are not unique, so an unknown create cannot be safely confirmed by name; the operation selects `uncertain` at the send cap. `updateCampaignStatus` and `removeCampaign` use `safe` repeat because they set absolute provider state. Enabling a campaign can start spending its linked budget.

In [Google Cloud Console](https://console.cloud.google.com/apis/credentials), enable Google Ads API, configure OAuth consent with the `adwords` scope, and create a Web application client with the exact redirect URI displayed by Dex Web. Google Ads now assigns API access to the Cloud project: Test access covers test accounts; production accounts require an approved access level. [Developer tokens are no longer required](https://developers.google.com/google-ads/api/docs/api-policy/developer-token) for this API.

Live Google consent, token refresh, Google Ads reads and writes, production access, and Dex Web field rendering have not been verified in this checkout. Provider-fake conformance and the mock-backed Go Flow passed locally against Dex.
