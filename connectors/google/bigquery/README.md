# Google BigQuery connector

The Go, Python, and TypeScript `listDatasets` Query lists one bounded page of datasets visible to the connected Google account in a specified project. The Go module also provides `getDataset`, `listTables`, `getTable`, `listTableRows`, `runReadQuery`, and `getQueryResults` as `safe` Queries. The runnable [Go](go/examples/datasets/README.md), [Python](python/examples/datasets/README.md), and [TypeScript](typescript/examples/datasets/README.md) Flows use the static `google-bigquery` Dex Web connection. The Go Worker registers both dataset and table listing Flows.

`runReadQuery` accepts one `SELECT` statement without comments or semicolons, requires a positive `maximumBytesBilled` limit in bytes, and returns up to 100 rows per call. A `pending` branch returns the provider job ID; use `getQueryResults` with that ID to poll and page through results. Metadata and table row listing also return bounded pages. BigQuery cell values retain their provider JSON types. Queries can incur BigQuery charges even when they only read data.

In [Google Cloud Console](https://console.cloud.google.com/apis/credentials), select a project, enable BigQuery API, configure OAuth consent with the `bigquery.readonly` scope, and create a Web application client with the exact redirect URI displayed by Dex Web. Supply the project and dataset IDs from BigQuery Studio > Explorer as operation input; leave the connection defaults blank unless a trusted gateway or larger response requires an override. The [datasets.list](https://docs.cloud.google.com/bigquery/docs/reference/rest/v2/datasets/list), [tables.list](https://docs.cloud.google.com/bigquery/docs/reference/rest/v2/tables/list), [tabledata.list](https://docs.cloud.google.com/bigquery/docs/reference/rest/v2/tabledata/list), and [jobs.query](https://docs.cloud.google.com/bigquery/docs/reference/rest/v2/jobs/query) references define these endpoints. Row insertion needs a broader OAuth scope and is not included so existing connections keep working.

Live Google consent, token refresh, BigQuery reads, and Dex Web field rendering have not been verified in this checkout. Provider-fake conformance and the mock-backed table Flow passed against local Dex.
