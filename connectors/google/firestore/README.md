# Cloud Firestore connector

The Go, Python, and TypeScript `listDocuments` Queries list a bounded page of document resource names in a top-level collection of the `(default)` database. Go also provides `listDocumentDetails`, `getDocument`, `createDocument`, `putDocument`, `deleteDocument`, `runDocumentQuery`, and `listRootCollections`. `createDocument` uses a chosen unused ID and bounded sends; `putDocument` absolutely replaces or creates the chosen document; deletion treats absence as complete. The runnable [Go](go/examples/documents/README.md), [Python](python/examples/documents/README.md), and [TypeScript](typescript/examples/documents/README.md) Flows use the static `google-firestore` Dex Web connection. Nested collections and change events remain outside this capability.

In [Google Cloud Console](https://console.cloud.google.com/apis/credentials), select a project, enable Cloud Firestore API, configure OAuth consent with the `datastore` scope, and create a Web application client with the exact redirect URI displayed by Dex Web. Find the project, collection, and document IDs under Firestore > Databases > (default) > Documents. The [Firestore REST reference](https://firebase.google.com/docs/firestore/reference/rest/v1/projects.databases.documents) defines document field Value JSON, structured queries, and pagination. Write inputs use Firestore field Value objects, for example `{"title":{"stringValue":"Hello"}}`; query inputs require `structuredQueryJson` with a `limit` from 1 through 100. Do not put secrets in document fields returned to Dex Flows.

Live Google consent, token refresh, Firestore reads, and Dex Web field rendering have not been verified in this checkout.
