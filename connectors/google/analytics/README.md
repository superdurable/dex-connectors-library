# Google Analytics 4 connector

The Go, Python, and TypeScript connectors run a bounded GA4 report, read property metadata, and list one page of audiences. The Go module also runs a bounded realtime report and lists properties and data streams. The [Go Flows](go/examples/property/README.md), [Python property Flow](python/examples/property/README.md), and [TypeScript property Flow](typescript/examples/property/README.md) use the static `google-analytics-4` Dex Web connection.

## Connection setup

In [Google Cloud Console](https://console.cloud.google.com/apis/credentials), select a project and enable **Google Analytics Data API** and **Google Analytics Admin API** under **APIs & Services → Library**. Configure OAuth consent, add `analytics.readonly` under **Data Access**, and add test users while an External app remains in Testing. Create a Web application under **Clients**, register the redirect URI displayed by Dex Web, then save its Client ID and Client Secret in the connection. Authorize a Google account with Viewer or higher access to the relevant GA4 property. Dex requests offline access for token renewal.

Find the numeric Property ID in **Google Analytics → Admin → Property settings → Property ID** and pass it to each operation. `runReport` takes an inclusive `YYYY-MM-DD` range, up to nine dimension names, one to ten metric names, and an optional row `limit` up to 10000 that defaults to 100 when omitted or zero. `listAudiences` takes an optional `pageSize` up to 200 that defaults to 50 and returns a cursor for the next page. The API origins, timeout, and response limit have manifest defaults; only override them for a trusted gateway or known operational need. Tokens remain Dex secrets and never enter Flow input or results.

`runRealtimeReport` accepts up to nine dimensions, one to ten metrics, and a minute range in the last 30 minutes; omitted range uses minutes 29 through 0. `listProperties` needs the numeric Account ID from **Analytics → Admin → Account settings → Account ID**. `listDataStreams` uses the numeric Property ID. Both list calls accept a page size up to 200 and return a cursor. All new Go operations are `safe` Queries and work with the existing `analytics.readonly` scope. Configuration writes require broader OAuth scopes and are outside this release.

The [GA4 Data API report](https://developers.google.com/analytics/devguides/reporting/data/v1/rest/v1beta/properties/runReport) and [realtime report](https://developers.google.com/analytics/devguides/reporting/data/v1/rest/v1beta/properties/runRealtimeReport), plus Admin API [property listing](https://developers.google.com/analytics/devguides/config/admin/v1/rest/v1beta/properties/list), [data stream listing](https://developers.google.com/analytics/devguides/config/admin/v1/rest/v1beta/properties.dataStreams/list), and [audience listing](https://developers.google.com/analytics/devguides/config/admin/v1/rest/v1alpha/properties.audiences/list) define these operations. Provider authorization and live API behavior have not been verified in this checkout. Mock-backed realtime report execution passed against local Dex.
