# FreshBooks connector

The Go, [Python](python/README.md), and [TypeScript](typescript/README.md) packages implement `getInvoice` using FreshBooks' [single-invoice endpoint](https://www.freshbooks.com/api/invoices). The Query takes a non-secret accounting `accountId` and positive numeric `invoiceId`. It returns the invoice number, exact decimal amount as a string, currency code, and payment status. HTTP 404 selects the optional `missing` branch; 429, timeout, server, and transport failures retry. Malformed responses and definitive rejections have separate optional branches.

Create an OAuth app in [FreshBooks Developer hub](https://my.freshbooks.com/#/developer) under Apps > Create New App. Add `user:profile:read` and `user:invoices:read`, register the exact HTTPS Dex Web redirect URI without query parameters, and copy the app's client ID, secret, and the same redirect URI into the `freshbooks` connection. FreshBooks requires that URI again when refreshing a token. Dex stores rotating access and refresh tokens. To find the accounting account ID, call [Identity Info](https://www.freshbooks.com/api/identity_model) and use `business_memberships[].business.account_id`; the business ID is different. Pass the account ID and invoice ID into the Flow input from a trusted source.

The [Go](go/examples/invoice/README.md), [Python](python/examples/invoice/README.md), and [TypeScript](typescript/examples/invoice/README.md) examples use the static `freshbooks` connection. The [Go-recorded conformance scenarios](../../conformance/connectors/freshbooks/scenarios.json) cover provider branches and retries. Live FreshBooks authorization, account lookup, and invoice behavior have not been verified in this checkout.
