# Product documentation voice

Applies to Markdown under `docs/`.

- Write plain, direct English with short sentences and concrete nouns.
- Use Dex terms exactly: Flow, Step, Attribute, Stream, Trigger, RPC, and Timer.
- Use inline code normally for identifiers in Markdown.
- Avoid marketing tone, chatbot filler, stacked synonyms, and repeated prose.
- Copy application snippets from runnable examples and link their source paths.

Cursor mirror: `.cursor/rules/docs-writing.mdc`.
